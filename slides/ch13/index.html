Nine questions, one toolkit

Act I · The tension

Regression describes — but can it explain why?

By now we can fit a line, add controls, and read a slope. But a slope is only an association: bigger houses cost more, richer countries have better institutions. Does the regressor cause the outcome?

This chapter runs nine case studies on real data — and the last four import a deliberate design (RCT, DiD, RD, IV) that turns a regression slope into a causal claim.

The chapter is a tour: same estimator (OLS/IV via pyfixest), nine very different questions. The throughline is the climb from description to causation.

Where we’re going

  • Multiple regression on observational data — and why controls aren’t enough
  • Log-log models — elasticities and returns to scale
  • Omitted variables bias — how a missing control flips a sign
  • Robust & clustered standard errors — honest uncertainty
  • Four research designs — RCT, difference-in-differences, regression discontinuity, instrumental variables

Five ideas anchor this chapter

  • Production function — inputs \(\to\) output; Cobb–Douglas \(Q = AK^{\beta_2}L^{\beta_3}\) is linear in logs
  • Constant returns to scale — doubling inputs doubles output, i.e. \(\beta_2 + \beta_3 = 1\)
  • Selection bias — the units we observe aren’t a random slice; random assignment is the fix
  • Parallel trends — the DiD assumption: absent treatment, groups move together
  • Counterfactual — the unobserved “what would have happened”; every design imputes it differently

A credible causal estimate isn’t a better regression — it’s a better source of variation.

The case files

Act II · The investigation

13.1 — Multiple regression: what drives school performance?

!pip install -q pyfixest                     # pyfixest not preinstalled in Colab
import pandas as pd                          # tabular data
import pyfixest as pf                         # OLS/IV with R-style formulas

url  = "https://raw.githubusercontent.com/quarcs-lab/data-open/master/AED/AED_API99.DTA"
data = pd.read_stata(url)                    # 807 California high schools, 1999

# API score on parent education + poverty, language, calendar, teacher quality
fit = pf.feols("api99 ~ edparent + meals + englearn + yearround + credteach + emerteach",
               data=data, vcov="HC1")        # HC1 = heteroskedasticity-robust SEs
fit.summary()                                # edparent ≈ +74 API pts/yr, even with controls

↗ Try it in Colab

Parent education survives every control (~74 points/year) — but meals, edparent, englearn are so correlated that isolating one effect is genuinely hard.

13.2 — Logs turn a production function into a regression

import numpy as np                           # np.log for the transform
# Cobb–Douglas  Q = A·K^β2·L^β3  ⇒  ln Q = β1 + β2 ln K + β3 ln L
url  = "https://raw.githubusercontent.com/quarcs-lab/data-open/master/AED/AED_COBBDOUGLAS.DTA"
data = pd.read_stata(url)                    # 24 yrs US manufacturing, 1899–1922

data[["lnq","lnk","lnl"]] = np.log(data[["q","k","l"]])   # log all three

fit = pf.feols("lnq ~ lnk + lnl", data=data)              # elasticities = coefficients
b = fit.coef()
print(b["lnk"], b["lnl"], b["lnk"] + b["lnl"])            # 0.23, 0.81, sum ≈ 1.04

↗ Try it in Colab

Capital elasticity \(\approx 0.23\), labor \(\approx 0.81\). Their sum \(\approx 1.04\), and an \(F\)-test of \(\beta_2+\beta_3=1\) gives \(p\approx 0.64\) — constant returns to scale.

The log-linear model tracks output across 24 years

Actual vs. predicted manufacturing output, 1899–1922 (fitted values retransformed by \(e^{\hat\sigma^2/2}\)). The two series move together — R² ≈ 0.96.

Because the model lives in logs, coefficients are elasticities and fitted levels need the \(e^{\hat\sigma^2/2}\) retransformation.

13.3 — A missing control can flip the sign

The Phillips curve — higher unemployment, lower inflation — worked before 1970 and reversed after. Same two variables, opposite slope.

The curve didn’t vanish — it was always conditional on expected inflation, the omitted variable.

Omitted variables bias, quantified

\[E[b_2] = \beta_2 + \beta_3\,\gamma\]

The bivariate slope equals the true slope plus the omitted variable’s effect (\(\beta_3\)) times how it co-moves with the regressor (\(\gamma\)).

Post-1970: \(\beta_2 \approx -0.13\) (true), \(\beta_3 \approx +1.15\) (expectations), \(\gamma \approx +0.34\) (both rose with oil shocks).

\(E[b_2] = -0.13 + 1.15\times0.34 \approx +0.26\) — almost exactly the \(+0.27\) we saw. The formula explains the reversal.

13.4 — Grouped data needs clustered standard errors

url  = "https://raw.githubusercontent.com/quarcs-lab/data-open/master/AED/AED_AUTOSMPG.DTA"
data = pd.read_stata(url)                    # 26,995 vehicles, 1980–2006 (pre-logged vars)

# log-log fuel economy; cluster SEs by manufacturer (shared tech → correlated errors)
fit = pf.feols("lmpg ~ lhp + lcurbwt + ltorque + year",
               data=data, vcov={"CRV1": "mfr"})   # CRV1 = cluster-robust by mfr
fit.summary()                                # weight elasticity ≈ −0.56 (the big one)

print(data["mfr"].nunique())                 # 39 clusters → more honest (wider) SEs

↗ Try it in Colab

Weight dominates (\(-0.56\)): technology added ~1–2%/yr efficiency, but buyers “spent” it on heavier, more powerful cars. Ignoring clustering would understate the SEs.

Four ways to a counterfactual

Act II · continued — designs that identify causation

RCT — randomize, and selection bias disappears

url  = "https://raw.githubusercontent.com/quarcs-lab/data-open/master/AED/AED_HEALTHINSEXP.DTA"
data = pd.read_stata(url).query("year == 1")   # RAND experiment, 5,639 person-yrs

# spending on randomly-assigned plan dummies (free care = omitted baseline)
fit = pf.feols("spending ~ coins25 + coins50 + coins95 + coinsmixed + coinsindiv",
               data=data, vcov={"CRV1": "idfamily"})   # cluster by family
fit.summary()                                   # all plan coefs < 0 vs free care

# joint F-test: do plans matter?  F ≈ 11.4, p < 0.001 → yes

↗ Try it in Colab

Random assignment makes the groups identical in expectation — so the plan coefficients are causal. Cost-sharing lowers spending (moral hazard is real, and moderate).

Difference-in-differences — subtract the common trend

url  = "https://raw.githubusercontent.com/quarcs-lab/data-open/master/AED/AED_HEALTHACCESS.DTA"
data = pd.read_stata(url)                    # 1,071 S. African children, 1993 vs 1998

# waz = weight-for-age z-score; postXhigh is the DiD interaction = the effect
fit = pf.feols("waz ~ hightreat + post + postXhigh",
               data=data, vcov={"CRV1": "idcommunity"})
fit.summary()                                # postXhigh ≈ +0.52 SD, p ≈ 0.03

↗ Try it in Colab

\[\text{DiD} = (\bar Y_{T,1}-\bar Y_{T,0}) - (\bar Y_{C,1}-\bar Y_{C,0})\]

New clinics raised child nutrition by \(\approx 0.52\) SD — causal if parallel trends hold (low-treatment communities proxy the counterfactual).

Regression discontinuity — compare at the knife’s edge

url  = "https://raw.githubusercontent.com/quarcs-lab/data-open/master/AED/AED_INCUMBENCY.DTA"
data = pd.read_stata(url).dropna(subset=["vote"])   # 1,390 US Senate elections

# vote(t+1) on winning(t), controlling linearly for the margin that determined it
fit = pf.feols("vote ~ win + margin", data=data, vcov="HC1")
fit.summary()                                # win ≈ +4.8 pp, p < 0.001
print(fit.confint().loc["win"])              # tight 95% CI around the jump

↗ Try it in Colab

At margin \(\approx 0\), barely-winners and barely-losers are identical except incumbency — so the \(+4.8\) pp jump is the causal incumbency advantage (a local estimate).

Instrumental variables — borrow exogenous variation

url  = "https://raw.githubusercontent.com/quarcs-lab/data-open/master/AED/AED_INSTITUTIONS.DTA"
data = pd.read_stata(url)                    # 64 former colonies (Acemoglu et al.)

ols = pf.feols("logpgp95 ~ avexpr", data=data, vcov="HC1")   # biased: endogenous
print(ols.coef()["avexpr"])                  # ≈ 0.52

# 2SLS: instrument institutions (avexpr) with log settler mortality (logem4)
iv = pf.feols("logpgp95 ~ 1 | avexpr ~ logem4", data=data, vcov="HC1")
iv.summary()                                 # first-stage F ≈ 16 > 10 (strong)
print(iv.coef()["avexpr"])                   # ≈ 0.94  → ~157% higher GDP per unit

↗ Try it in Colab

Settler mortality (1700s) shifts institutions but not modern GDP directly. IV (\(0.94\)) exceeds OLS (\(0.52\)) — measurement error had biased OLS toward zero.

Reading it right

Act III · The resolution

The ladder of credibility

Objection. “Just add enough controls and any regression is causal.”

Response. Controls only close the confounders you can measure. The four designs instead engineer a credible counterfactual — random assignment (RCT), a common trend to subtract (DiD), near-identical units at a cutoff (RD), or exogenous variation from an instrument (IV).

Identification comes from the design, not the dataset. Ask “where does the variation come from?” before “what’s the coefficient?”

What to carry forward

  • One estimator (pf.feols), nine questions — from school scores to the wealth of nations.
  • Logs give elasticities; the sum of Cobb–Douglas elasticities tests returns to scale.
  • A relevant omitted variable can flip a sign — \(E[b_2]=\beta_2+\beta_3\gamma\) says exactly how much.
  • Match the standard error to the data: HC1 for heteroskedasticity, CRV1 for clustered groups.
  • RCT / DiD / RD / IV each impute the counterfactual a different way — and each rests on an assumption you must defend.

Nine case files, one lesson: a causal slope is earned by design, not by adding controls.
