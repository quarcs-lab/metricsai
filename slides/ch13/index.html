Nine questions, one toolkit

Act I · The tension

Welcome to the chapter that pulls the whole book together. Every case study uses the same estimator (OLS, and in 13.8 its IV cousin) on a different real dataset. What changes from case to case is the question, the data structure, the standard errors, and — above all — the source of variation that lets us interpret a slope.

Regression describes — but can it explain why?

By now we can fit a line, add controls, and read a slope. But a slope is an association: schools with better-educated parents score higher; countries with stronger property rights are richer. Does the regressor cause the outcome?

This chapter works through nine case studies on real data. The first four push observational regression as far as it goes. The last four bring in a research design (an RCT, difference-in-differences, a regression discontinuity, or an instrumental variable) that turns a slope into a causal claim.

The question running through every case is the same: where does the variation in the regressor come from?

Frame the deck as a climb: describe → specify → diagnose bias → design for causation. Each case is self-contained, with its own data, code, output and interpretation, so you can teach any case on its own. Use the agenda on the next slide to jump.

The climb: from description to causation

  • Describe (13.1, 13.4): conditional associations, with controls and honest SEs
  • Impose structure (13.2): a theory-based functional form makes the coefficients interpretable as elasticities and gives a testable restriction
  • Diagnose bias (13.3): the omitted-variables formula tells us how much a missing regressor distorts a slope
  • Design for causation (13.5–13.8): an RCT, DiD, RD or IV builds a credible counterfactual

Controls can only close the confounders we measure. A design closes the ones we don’t.

The ladder idea: each rung adds an assumption that is easier to defend. Description makes no causal claim. Structure adds theory. The OVB formula tells us the direction and size of bias. Designs replace “I controlled for everything” (unverifiable) with a specific, defensible identifying assumption: random assignment, parallel trends, continuity at a cutoff, or an exclusion restriction.

One estimator, three ways to be honest about uncertainty

SE type pyfixest syntax Use when errors are… Cases
Heteroskedasticity-robust vcov="HC1" independent, unequal variance (cross-sections) 13.1, 13.7, 13.8
HAC (Newey–West) vcov="NW" + time_id, lag autocorrelated over time (time series) 13.2, 13.3

The coefficient is identical under all three. Only the standard errors, and therefore the \(t\)-statistics, \(p\)-values and confidence intervals, change.

Match the standard error to how the data were generated. In 13.4, clustering makes the SEs 6–9× larger than HC1.

The chapter uses one estimation function, pf.feols, throughout. The vcov argument changes only the inference. HC1 handles heteroskedasticity across independent observations. Newey–West (HAC) also allows correlation between nearby time periods — the chapter uses 3 lags for the 24-year Cobb–Douglas series and 5 lags for the 45-year post-1970 Phillips series. CRV1 allows arbitrary correlation inside each cluster (manufacturer, family, community). We will see in 13.4 that this choice is not cosmetic.

Five ideas anchor this chapter

  • Production function: inputs \(\to\) output. Cobb–Douglas \(Q = AK^{\beta_2}L^{\beta_3}\) is linear in logs
  • Constant returns to scale: doubling every input doubles output, i.e. \(\beta_2 + \beta_3 = 1\)
  • Selection bias: treated and untreated units differ before treatment; random assignment removes the difference
  • Parallel trends: the DiD assumption that, without treatment, both groups would have moved together
  • Counterfactual: the unobserved “what would have happened”; every design imputes it differently

A credible causal estimate is not a better regression. It is a better source of variation.

These are the chapter’s Key Concepts. Production function and CRS anchor 13.2; selection bias anchors 13.5; parallel trends anchors 13.6; the counterfactual idea ties 13.5–13.8 together.

Why these are associations, not causal effects

What the regression holds fixed

  • the six measured characteristics
  • nothing else

What it cannot hold fixed

  • family income, home resources, private tutoring
  • which families choose which districts
  • how teachers sort toward easier schools

edparent is a proxy for a whole bundle of advantages, so 73.9 is a conditional association, not “the effect of sending parents back to school”.

Case 13.2 · Does doubling inputs double output?

Cobb–Douglas production function · log-log model · HAC standard errors

Case 13.2: Douglas’s U.S. manufacturing data, 1899–1922. Tools: log transformation, elasticities, a test of a linear restriction, retransformation of log predictions, HAC standard errors for time series.

The question: returns to scale in U.S. manufacturing

The Cobb–Douglas production function maps capital \(K\) and labor \(L\) into output \(Q\):

\[Q = A\,K^{\beta_2}\,L^{\beta_3}\]

If \(\beta_2 + \beta_3\) is… Returns to scale Doubling both inputs…
\(= 1\) constant doubles output
\(> 1\) increasing more than doubles output
\(< 1\) decreasing less than doubles output

Returns to scale come down to a single number, \(\beta_2 + \beta_3\), which we can estimate and test.

A is total factor productivity (the technology level). β₂ and β₃ are the output elasticities of capital and labor. Scaling both inputs by λ multiplies output by λ^(β₂+β₃), which is why the sum decides returns to scale. Competitive-market theory often predicts constant returns.

Taking logs turns a multiplicative model into a linear regression

\[\ln Q = \underbrace{\ln A}_{\beta_1} + \beta_2 \ln K + \beta_3 \ln L + u\]

The model is now linear in its parameters, so OLS applies. Each slope is an elasticity: \(\beta_2 = \partial \ln Q / \partial \ln K\), the percentage change in output per 1% change in capital, holding labor fixed.

Logs do two jobs here: they make the model estimable by OLS, and they make the coefficients unit-free elasticities.

Key Concept 13.2. Because both sides are in logs, a coefficient measures a proportional response. Strictly, “a 1% change in K changes Q by β₂%” is a marginal (calculus) statement; for finite changes it is an approximation that is excellent for small changes.

The data: 24 years of output, capital and labor (1899 = 100)

Why HAC standard errors?

  • Time series: booms, recessions and technology shocks persist, so errors are autocorrelated
  • Volatility differs across periods (e.g. World War I), so errors are heteroskedastic
  • Newey–West (HAC) SEs allow for both; the chapter uses 3 lags

Capital grew much faster than output or labor. How the regression splits output growth between the two inputs is the elasticity question.

Douglas (1976) data; all series are indices with 1899 = 100. Default OLS SEs assume uncorrelated, homoskedastic errors, which is wrong here. HC1 fixes heteroskedasticity but ignores autocorrelation. HAC (heteroskedasticity- and autocorrelation-consistent) SEs fix both. With only 24 observations, even HAC SEs are themselves imprecise.

Code: test constant returns with the HAC covariance matrix

# continues from the previous block
from scipy import stats                     # F distribution for the p-value
R = np.array([0.0, 1.0, 1.0])               # restriction vector: picks out β_K + β_L
b_hat = fit_cobb.coef().values              # coefficients [Intercept, lnk, lnl]
V_hac = fit_cobb._vcov                      # Newey–West (HAC) covariance matrix
df_resid = fit_cobb._N - len(b_hat)         # residual degrees of freedom: 24 − 3 = 21
f_stat = (R @ b_hat - 1.0)**2 / (R @ V_hac @ R)   # Wald statistic for H0: β_K + β_L = 1
p_value = 1 - stats.f.cdf(f_stat, 1, df_resid)    # p-value from F(1, 21)
print(R @ b_hat, f_stat, p_value)           # estimated sum, F, p

To predict levels from a log model, exponentiate and rescale by \(e^{\hat\sigma^2/2}\); here \(\hat\sigma = 0.058\), so the correction is tiny (×1.0017).

The predicted series follows actual output closely, with the largest misses in the 1920–22 swings.

Caveats: why 24 trending observations call for humility

  • Trending series: \(Q\), \(K\) and \(L\) all rise over time, so part of the \(R^2 = 0.957\) is a shared trend, not a production relationship (the spurious-regression worry)
  • Technology held constant: \(A\) is a single constant; omitted technical progress that grew with capital would load onto \(\hat\beta_K\)
  • Small sample: 24 points, and HAC SEs are themselves noisy with so few years
  • Aggregation: one “representative” manufacturing sector stands in for many industries

The CRS test is informative, but treat the separate elasticities as fragile.

These are standard caveats for an aggregate time-series production function, not results the chapter computes. The spurious-regression problem (regressing one trending series on another) is covered in time-series chapters. A natural extension would add a time trend to proxy technical change; this deck does not estimate it.

Case 13.3 · Why did the Phillips curve break?

Omitted variables bias · time series · HAC standard errors

Case 13.3: the most important diagnostic case in the chapter. The same two variables give opposite slopes in two periods; the omitted-variables-bias formula explains exactly why.

The question: is there a stable unemployment–inflation trade-off?

  • Phillips (1958): lower unemployment went with higher wage inflation, so policymakers saw a menu: choose a point on the curve
  • 1970s stagflation: high unemployment and high inflation together, and the menu fell apart
  • Friedman–Phelps: the curve shifts with expected inflation; leave expectations out and the curve is misspecified

\[\text{Inflation}_t = \beta_1 + \beta_2\,\text{Urate}_t + \beta_3\,\text{ExpInflation}_t + u_t\]

If expected inflation belongs in the model, omitting it is not harmless. It can distort, even reverse, the unemployment slope.

Data: AED_PHILLIPS.DTA, U.S. 1949–2014 (66 years). inflgdp = annual inflation from the GDP deflator (%); urate = civilian unemployment rate (%); inflgdp1yr = one-year-ahead expected inflation from the Survey of Professional Forecasters. In this dataset the expectations series is available only from 1970 onward, so the augmented model can only be run post-1970.

The OVB formula: what an omitted regressor does to a slope

\[\underbrace{y = \beta_1 + \beta_2 x + \beta_3 z + u}_{\text{long (true) model}} \qquad \underbrace{z = \gamma_1 + \gamma\,x + v}_{\text{auxiliary regression}}\]

Substitute \(z\) into the long model and regress \(y\) on \(x\) alone:

\[E[b_2] = \beta_2 + \underbrace{\beta_3\,\gamma}_{\text{omitted variables bias}}\]

The bias is (effect of the omitted \(z\) on \(y\)) × (how \(z\) moves with the included \(x\)). It vanishes only if \(\beta_3 = 0\) or \(\gamma = 0\).

Key Concept 13.5. Direction of the bias: sign(β₃) × sign(γ). If z raises y (β₃ > 0) and rises with x (γ > 0), the short slope is biased upward, and enough upward bias can turn a negative true slope positive. With OLS on the same sample, the in-sample version b₂(short) = β̂₂ + β̂₃·γ̂ holds exactly, not just in expectation.

The chapter calls this a “perfect match”. It is perfect by construction: for OLS on a common sample the decomposition is an algebraic identity. Its value is in attributing the short slope: −0.128 of genuine trade-off plus +0.393 of omitted-variable bias. Economic story: 1970s supply shocks (oil) raised unemployment and inflation expectations together, so γ > 0; and expectations push inflation up (β₃ > 0); so the bias is positive.

Caveats: the trade-off is restored in sign, not proven

  • Imprecision: the augmented slope (\(-0.128\), \(p = 0.12\)) and \(\hat\gamma\) (\(p = 0.086\)) are not significant at 5%
  • Measurement: expected inflation is a forecasters’ survey, a proxy for what wage- and price-setters actually expected
  • Simultaneity: inflation and unemployment are both outcomes of the same shocks and policies, so this is not a causal structural equation
  • Other omitted variables: supply shocks and policy regimes can still bias the long model

The OVB formula is a diagnostic: it tells us the direction and size of the bias from a named omitted variable. It cannot rule out the omitted variables we have not named.

The chapter itself notes the post-1970 slope (p ≈ 0.42) and the augmented urate coefficient (p ≈ 0.12) are not significant. The broader lesson for the policy debate: once expectations adjust, there is little long-run trade-off to exploit, which is why central banks focus on anchoring expectations.

Why cluster by manufacturer?

Vehicles from the same manufacturer share engine platforms, engineering teams, design philosophy and testing practices. So their regression errors are correlated within the manufacturer.

Default / HC1 SEs assume

  • 26,995 independent pieces of information
  • Too-small SEs, too-large \(t\)-stats

Cluster-robust (CRV1) SEs allow

  • any correlation inside each of the 39 manufacturers
  • independence only across manufacturers

With correlated errors, the effective sample size is closer to the number of clusters than to the number of rows.

Key Concept 13.6. Ignoring within-cluster correlation understates uncertainty and leads to false rejections. CRV1 is pyfixest’s standard cluster-robust estimator with a small-sample correction.

Act II-b · Four designs that identify causation

Cases 13.5–13.8 · RCT · DiD · RD · IV

From here on, each case asks a causal question, and each answers it with a design that supplies a credible counterfactual. The estimator is still OLS (or 2SLS); what changes is why we believe the slope.

Why a raw comparison is not a causal effect

\[\underbrace{E[Y \mid D{=}1] - E[Y \mid D{=}0]}_{\text{observed difference}} = \underbrace{E[Y_1 - Y_0 \mid D{=}1]}_{\text{effect on the treated (ATT)}} + \underbrace{E[Y_0 \mid D{=}1] - E[Y_0 \mid D{=}0]}_{\text{selection bias}}\]

\(Y_1\), \(Y_0\): potential outcomes with and without treatment. We only ever observe one of them per unit. The other is the counterfactual.

Every design in this act is a strategy for driving the selection-bias term to zero.

Selection bias is the difference the treated and untreated would have shown even without treatment. In observational data it is generally non-zero: people who buy generous insurance expect to need care; parties that win were already strong; rich countries can afford good institutions. This is the potential-outcomes way of saying “confounding”.

Four ways to build the counterfactual

Design Where the counterfactual comes from Case
RCT a randomly assigned control group 13.5 RAND health insurance
Difference-in-differences the control group’s change over time 13.6 South African clinics
Regression discontinuity units just on the other side of a cutoff 13.7 Senate elections
Instrumental variables variation in treatment driven only by an instrument 13.8 colonial institutions

Each design swaps the unverifiable “I controlled for everything” for one specific assumption you can argue about.

Case 13.5 · Does cost-sharing reduce medical spending?

Randomized controlled trial · RAND Health Insurance Experiment · SEs clustered by family

Case 13.5: the gold standard. Tools: regression on treatment dummies, a joint F-test with cluster-robust covariance, and the logic of random assignment.

The question: does cheaper care mean more care?

Moral hazard: if insurance makes care cheaper at the point of use, do people use more of it? That question drives every debate about deductibles and co-pays.

Why observational data fail. People choose their insurance:

  • those who expect to be sick buy more generous plans
  • income, education and health all affect both plan choice and spending

In observational data, “generous plan → higher spending” mixes the plan’s effect with who chose it.

Reverse causation too: health status affects insurance choice. Comparing spending across self-chosen plans therefore estimates the effect plus selection bias, with no way to separate them.

The design: random assignment to insurance plans

RAND Health Insurance Experiment (1974–1982)

  • families randomly assigned to plans
  • coinsurance (the share of the bill you pay): 0% (free care), 25%, mixed 25/50%, 50%, 95%, or an individual deductible
  • followed for 3–5 years

Why it works

  • assignment is independent of health, income and preferences
  • so the groups are identical in expectation
  • selection bias \(= 0\) in expectation, so the difference in means estimates the causal effect of each plan vs free care

Randomization does not equalize the groups exactly. It makes every difference before treatment pure chance, which standard errors already account for.

Key Concept 13.7. Estimand: the average effect, among experiment participants, of being assigned to plan j rather than free care. Because families (not individuals) were assigned, outcomes of members of the same family are correlated, hence SEs clustered by family.

Code + output: do the plans matter jointly?

# continues from the previous block
import numpy as np                          # matrix algebra
from scipy.stats import f as f_dist         # F distribution
coef_names = ["coins25", "coins50", "coins95", "coinsmixed", "coinsindiv"]
coefs = np.array([fit_rct.coef()[c] for c in coef_names])        # the 5 plan effects
idx = [list(fit_rct.coef().index).index(c) for c in coef_names]  # their positions
V_sub = fit_rct._vcov[np.ix_(idx, idx)]     # clustered covariance of the 5 effects
f_val = coefs @ np.linalg.inv(V_sub) @ coefs / len(coef_names)   # Wald F statistic
p_val = 1 - f_dist.cdf(f_val, len(coef_names), fit_rct._N - len(fit_rct.coef()))
print(f_val, p_val)                         # H0: all five plan effects = 0

↗ Try it in Colab

Result: \(F = 11.39\), \(p < 0.001\). We reject that insurance generosity is irrelevant: plan design causally changes spending.

H0: all five plan coefficients are zero (no plan differs from free care). F(5, 5,633) = 11.39, p ≈ 6 × 10⁻¹¹. The Wald statistic uses the cluster-robust covariance matrix, so the joint test is consistent with the clustered SEs.

Interpretation: moral hazard is real, and moderate

  • Causal reading: because plans were randomized, the −$1,108 for the 95% plan is the effect of facing 95% coinsurance instead of free care, about 51% less spending in year 1
  • Magnitude: cost-sharing cuts spending by roughly a quarter to a half, depending on the plan; that is meaningful but not dramatic
  • \(R^2 = 0.007\) is irrelevant to causality: individual health shocks drive most of the spending variation. A low \(R^2\) means we predict individuals poorly, not that the effect is biased
  • Policy: free care raises use; cost-sharing lowers costs but may also cut necessary care

An RCT turns a difference in means into a causal effect. Precision, not bias, is the remaining problem.

The chapter says the low R² “is actually good”. The more precise statement is that R² is irrelevant for identifying a causal effect: randomization guarantees unbiasedness regardless of R²; a low R² only implies that the outcome has a lot of other variation. The RAND results shaped U.S. health-insurance design (Medicare/Medicaid cost-sharing, later ACA debates).

Threats to an RCT: what can still go wrong

  • Attrition: if families who dislike their plan drop out (more likely under heavy cost-sharing), the remaining groups are no longer comparable
  • Non-compliance and refusal at enrollment can undo the balance that randomization created
  • Balance check (not run in the chapter): compare baseline age, income and health across plans; they should differ only by chance
  • External validity: six U.S. sites in the 1970s; health care has changed since
  • Ethics and cost: randomizing insurance is rarely possible, which is why the next three designs exist

Randomization identifies the effect for the people in the experiment. Its credibility then depends on keeping the randomized groups intact.

Standard RCT caveats. Aron-Dine, Einav and Finkelstein (2013, Journal of Economic Perspectives) revisit the RAND experiment and discuss differential attrition and refusal across plans. The dataset includes baseline covariates (age, famincome, educ, health status), so a balance table is an easy exercise.

Case 13.6 · Did free care improve child nutrition?

Difference-in-differences · South Africa, 1993 vs 1998 · SEs clustered by community

Case 13.6: no randomization, but a before/after comparison between more- and less-exposed communities. Tools: the 2×2 DiD table, the interaction regression, and the parallel-trends assumption.

The question: did the 1994 health reform improve child nutrition?

  • The policy (1994): post-apartheid South Africa made public primary care free for young children and pregnant women (studied by Tanaka 2014)
  • Who could benefit: free care helps only if a clinic is within reach
  • Treatment group: children in communities that had a clinic in 1993 (hightreat = 1); comparison group: children in communities without one
  • Outcome: waz, the weight-for-age \(z\)-score, a standard measure of child nutrition

Exposure to the reform depended on where a child lived, which gives a natural treatment and comparison group.

Data: AED_HEALTHACCESS.DTA, 1,071 children aged 0–4 in rural KwaZulu-Natal, surveyed in 1993 (before) and 1998 (after), 54 communities; source Tanaka (2014, AEJ: Economic Policy). The dataset labels hightreat as “= 1 if community has clinic in 1993”. (The chapter narrates this as “communities that got many new clinics”; the slides follow the dataset label and the source paper: treatment intensity is pre-existing clinic access to the newly free care.) Note the children in 1993 and 1998 are different children (two cohorts aged 0–4), not the same children followed over time.

The design: difference out both the level gap and the common trend

Group 1993 (pre) 1998 (post) Change
High treatment (clinic) \(\bar Y_{T,0}\) \(\bar Y_{T,1}\) \(\Delta_T\)
Low treatment (no clinic) \(\bar Y_{C,0}\) \(\bar Y_{C,1}\) \(\Delta_C\)

\[\text{DiD} = (\bar Y_{T,1} - \bar Y_{T,0}) - (\bar Y_{C,1} - \bar Y_{C,0}) = \Delta_T - \Delta_C\]

The first difference removes permanent gaps between communities. The second removes changes common to everyone (national trends, the economy).

Key Concept 13.8. Identifying assumption, parallel trends: without the reform, the treated communities’ mean waz would have changed by the same amount as the comparison communities’ (Δ_C). Estimand: the average effect on the treated (ATT), meaning children in communities with clinic access.

Naive vs design: two shortcuts, two different biases

Comparison Estimate What it gets wrong
After-only gap (1998: high − low) 0.391 ignores that treated children started 0.131 lower, so it is biased down
Before–after, treated only 0.867 credits the reform with the common improvement (+0.345), so it is biased up
Difference-in-differences 0.522 removes both the baseline gap and the common trend

Each single difference is contaminated by one confounder. Using both differences removes both.

Both naive numbers come straight from the 2×2 table (no new estimation). The before–after estimate (0.867) is 66% larger than DiD; the post-only gap (0.391) is 25% smaller. This is the “OLS vs design” thread: the naive comparisons are what you would report without a design.

Case 13.7 · Do parties gain from holding a Senate seat?

Regression discontinuity · U.S. Senate elections, 1914–2010 · HC1 standard errors

Case 13.7: a sharp cutoff (50% of the vote decides who wins) creates as-good-as-random variation in incumbency for close races. Tools: running variable, cutoff, the RD regression, and the locality of the estimate.

The question: is there an incumbency advantage?

Parties that hold a seat tend to win it again. But is that because holding the seat helps, or because parties that win were stronger to begin with?

The data (AED_INCUMBENCY.DTA): 1,390 U.S. Senate elections, 1914–2010

  • margin: Democratic margin of victory in election \(t\) (percentage points, −100 to +100)
  • win \(= 1\) if margin \(> 0\) (the Democrat won the seat)
  • vote: Democratic vote share in the next election for that seat, \(t+1\) (1,297 non-missing)

The unit is the party’s seat, so this case measures the party incumbency advantage: the gain to the Democratic party from having won the seat last time.

The chapter phrases the question as a candidate’s incumbency advantage. The dataset’s labels show the outcome is the Democratic party’s vote share in the next election, and the running variable is the Democratic margin in election t, so the estimand is the party-level incumbency effect (as in Lee 2008’s House study). The candidate may or may not run again.

The design: compare races that were barely won with races that were barely lost

  • Running variable: margin
  • Cutoff: margin \(= 0\)
  • Treatment: winning, which switches on sharply at the cutoff
  • Key assumption, continuity: without the treatment, average outcomes would vary smoothly through the cutoff

\[\text{vote}_{t+1} = \beta_1 + \beta_2\,\text{win}_t + \beta_3\,\text{margin}_t + u\]

\(\beta_2\) is the jump in the outcome at margin \(= 0\), after controlling for the smooth effect of the margin.

Within a hair of 50%, who wins is close to a coin flip, so winners and losers are comparable except for winning.

Key Concept 13.9. Estimand: the effect of winning at the cutoff, i.e. for close races. It is local by construction. The chapter’s specification imposes one common slope on both sides of the cutoff and uses every election, whatever its margin.

Naive vs design: comparing all winners with all losers is badly biased

Interpretation: a local, party-level causal effect

  • Local: it applies to close races, not to landslides; the advantage in safe seats is not identified

  • Mechanisms (not separated here): name recognition, fundraising, media access, constituent service

RD trades breadth for credibility: a very believable effect, for a narrow set of elections.

Selection bias is removed only at the cutoff; away from it, winners and losers differ systematically (as the naive 21.7 shows). The chapter’s policy discussion (term limits, campaign finance) goes beyond what the estimate itself identifies.

Threats: the estimate leans on a global linear fit

  • Global, not local: the chapter fits one straight line over margins from −100 to +100, including 45 uncontested races at ±100. Only 451 of 1,297 races are within ±10 points
  • Common slope: forcing the same slope on both sides can bias the jump if the true relationship bends near 0
  • Standard practice: local linear regression within a bandwidth around 0, with separate slopes on each side and a data-driven bandwidth (e.g. rdrobust), plus sensitivity checks
  • Sorting: if parties could manipulate very close outcomes, barely-winners would differ systematically. Check the density of margin and the balance of covariates at 0

The design is credible. How much to trust the specific 4.8 depends on the functional form, so a local robustness check is the next step.

These are standard RD practices, described, not estimated, in this deck. The chapter lists RD as “robust to model specification”; in practice RD estimates can be sensitive to polynomial order and bandwidth, which is why the local-linear, bandwidth-selected approach (Calonico, Cattaneo and Titiunik) is now standard. McCrary’s density test checks for sorting at the cutoff.

Case 13.8 · Do institutions cause prosperity?

Instrumental variables · two-stage least squares · 64 former colonies

Case 13.8: Acemoglu, Johnson and Robinson (2001). Tools: endogeneity, instrument relevance and exclusion, the first stage, 2SLS in pyfixest, the reduced form, and interpreting log outcomes.

The question: why are some countries rich and others poor?

Regress GDP on the quality of institutions and you get a strong positive slope. But institutions are endogenous:

Source of endogeneity Likely direction of OLS bias
Reverse causation: rich countries can afford better institutions upward
Omitted variables: geography, culture, history affect both likely upward
Measurement error: “institutions” is hard to measure toward zero (attenuation)

OLS mixes all three, and the biases pull in opposite directions, so we cannot even sign the net bias.

Measurement error in the regressor biases OLS toward zero (attenuation); reverse causation and positively-correlated omitted factors typically bias it upward. So the OLS estimate could be too big or too small, which is exactly when an instrument is needed.

The design: settler mortality as an instrument

The historical argument (AJR 2001):

Settler mortality (1600s–1800s) \(\to\) type of colonial institutions \(\to\) institutions today \(\to\) GDP today

  • High mortality: Europeans did not settle, and built extractive institutions
  • Low mortality: Europeans settled, and built institutions that protect property
  • Relevance: mortality must predict institutions, which the first stage tests
  • Exclusion: mortality must affect today’s GDP only through institutions. This cannot be tested

An instrument is valid only if it moves the treatment and has no other path to the outcome. The second condition rests on argument, not data.

Key Concept 13.10. Variables: logpgp95 = log PPP GDP per capita, 1995; avexpr = average protection against expropriation risk (0–10 index of institutional quality); logem4 = log settler mortality. Estimand: with heterogeneous effects, IV identifies a local average effect for the variation in institutions driven by settler mortality; with a constant effect, it is the causal effect.

IV = reduced form ÷ first stage

\[\hat\beta_{IV} = \frac{\text{effect of } Z \text{ on } Y}{\text{effect of } Z \text{ on } X} = \frac{-0.573}{-0.607} = 0.944\]

Reduced form: \(-0.573\) is the slope of log GDP on log settler mortality (bivariate OLS, same 64 countries).

IV rescales the instrument’s total effect on GDP by its effect on institutions. All the identifying power comes from settler mortality.

With one instrument and no other regressors, 2SLS equals the ratio of the reduced-form slope to the first-stage slope (indirect least squares). The reduced-form regression (logpgp95 on logem4) is computed for the slides; the ratio reproduces the chapter’s 0.944 exactly. If the exclusion restriction fails, so that mortality affects GDP through some other channel, the numerator includes that channel and the IV estimate is biased.

Exact conversions: e^0.944 = 2.57, so +157% (the chapter’s “2.57×”); e^0.522 = 1.69, so +69%. One-SD calculations: 0.944 × 1.47 = 1.39 log points → e^1.39 ≈ 4.0; 0.522 × 1.47 = 0.77 → ≈ 2.2. The “≈ 0.94%” style reading would be wrong: the outcome is in logs and the regressor in index points.

Why is IV larger than OLS?

  • The chapter’s explanation, attenuation: measurement error in avexpr biases OLS toward zero; IV, using a variable unrelated to that error, corrects it
  • Reverse causation and omitted variables would push OLS up, so a larger IV estimate is consistent with measurement error dominating
  • But other readings fit too: with heterogeneous effects, IV estimates a local effect for countries whose institutions were shaped by settler mortality, which need not equal the average effect
  • And if the exclusion restriction fails (e.g. the disease environment affects GDP directly), the IV estimate itself is biased

OLS < IV is consistent with attenuation bias. It does not prove it.

The chapter says IV > OLS points to measurement error as the dominant bias. That is a reasonable reading, and AJR (2001) make the same argument, but it is one of several explanations, and students should hold it with appropriate uncertainty.

Threats: everything rests on the exclusion restriction

  • Exclusion: settler mortality reflects the disease environment and geography, which may affect GDP directly, not only through institutions
  • Other channels: settlers brought human capital, language and legal origin, not just institutions
  • Data critique: the settler-mortality series has been challenged (e.g. Albouy 2012), and re-estimates with revised data are weaker
  • Weak-instrument margin: \(F = 16.3\) passes the \(F > 10\) rule, but recent work argues standard \(t\)-tests need a much stronger first stage
  • Small sample: 64 countries, so a few influential observations matter

IV is only as good as its story. Settler mortality is a famous and influential instrument, and a heavily debated one.

Standard IV caveats and the main published debate: Glaeser et al. (2004) argue settlers brought human capital; Albouy (2012, AER) questions the mortality data. Lee, McCrary, Moreira and Porter (2022, AER) show that valid 5% t-tests need first-stage F above about 104 under the conventional critical value. The chapter’s own caveat: results apply to former colonies, and institutional change is slow.

Every design buys credibility with an assumption. Know which assumption you bought, and for whom the estimate holds.

The estimand row matters as much as the estimate: each design answers a slightly different question. RD is local to close races; IV is local to the instrument-driven variation; DiD is for the treated group; the RCT is for experiment participants.

Which design fits your question?

  • Can you randomize the treatment? Run an RCT
  • Does treatment switch on at a known threshold of a score, margin or date? Use RD
  • Do you observe treated and untreated groups before and after treatment? Use DiD, and defend parallel trends
  • Is there a variable that shifts the treatment but affects the outcome only through it? Use IV, and defend exclusion
  • None of these? Then a regression with controls gives a conditional association; use the OVB formula to sign the likely bias

Start from the source of variation, not from the estimator. The estimator is almost always OLS or 2SLS.

A decision guide, not a strict algorithm: many real studies combine designs (e.g. DiD with an RD-style cutoff, or IV inside an RCT with imperfect compliance).

The bias goes in both directions across cases, so no “rule” says naive estimates are too large.

The tempting mistake — and the correction

Objection. “Just add enough controls and any regression becomes causal.”

Response. Controls close only the confounders you can measure. In 13.1, five controls left the parent-education slope almost unchanged, and that is no evidence it is causal. In 13.7, comparing winners with losers gives 21.7 points; the cutoff gives 4.8.

Identification comes from the design, not the dataset. Ask “where does the variation come from?” before asking “what is the coefficient?”

Steelman the objection: controls do help, and the OVB formula shows how. But stability of a coefficient when controls are added is not proof of causality, because the variables that matter most are often the ones you do not observe.

Five questions to ask of any coefficient

  1. Units: levels, logs or both? An elasticity, a semi-elasticity (\(100(e^b-1)\%\)), percentage points, or \(z\)-units?
  2. Conditional on what? Which variables are held fixed, and which are not?
  3. Which standard error? HC1, HAC or clustered: does it match how the data were generated?
  4. Where does the variation come from? Self-selection, randomization, a trend break, a cutoff, an instrument?
  5. For whom? Everyone (ATE), the treated (ATT), close races (local), or instrument-compliers (LATE)?

The most common misreadings come from skipping question 1: “4.8%” instead of 4.8 percentage points, “0.52 SD” without saying which SD, or “1%” for a percentage-point change.

A checklist students can apply to any regression output. The unit errors corrected in this deck: RD effect in percentage points (not %), DiD effect in reference-population z-units (not sample SDs), Phillips slope in percentage points of inflation per percentage point of unemployment, and log-outcome effects converted with e^b − 1.

What to carry forward

  • One estimator, nine questions: pf.feols from school scores to the wealth of nations
  • Logs give elasticities; the sum of Cobb–Douglas elasticities tests returns to scale
  • An omitted variable can flip a sign, and \(E[b_2]=\beta_2+\beta_3\gamma\) says exactly by how much
  • Match the standard error to the data: HC1, NW for time series, CRV1 for groups; in 13.4 clustering changed SEs 6–9×
  • RCT / DiD / RD / IV each impute the counterfactual differently, and each rests on an assumption you must defend
  • Wrangling is modeling: every sample restriction belongs in the write-up
