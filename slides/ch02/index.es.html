La pregunta

Acto I · Una variable

Tienes 171 números. ¿Y ahora qué?

Ingresos anuales de 171 mujeres de 30 años que trabajan a tiempo completo. Una columna de 171 cantidades en dólares no te dice nada a simple vista.

El resumen univariado es como comprimimos esa columna en un puñado de números — y unas cuantas imágenes — que revelan su centro, su dispersión y su forma.

Univariado = una sola variable. Antes de cualquier modelado, resumes. Este capítulo es la caja de herramientas: estadísticas de resumen para los números, gráficos para la forma.

Hacia dónde vamos

  • Resumir una variable con la media, la mediana, la dispersión y las estadísticas de forma
  • Visualizar datos numéricos — diagramas de caja, histogramas, densidad, gráficos de líneas
  • Comparar categorías con gráficos de barras y de pastel
  • Transformar datos sesgados con logaritmos y puntajes z
  • Suavizar series de tiempo con medias móviles y ajuste estacional

Seis ideas anclan este capítulo

  • Media vs. mediana — el promedio, arrastrado por los valores atípicos; frente al valor central honesto
  • Desviación estándar — la distancia típica de un punto respecto a la media
  • Cuartiles e RIC — \(Q_1\), \(Q_2\), \(Q_3\) dividen los datos en cuatro; RIC \(= Q_3 - Q_1\)
  • Asimetría — falta de simetría; \(> 1\) significa una cola derecha larga
  • Curtosis — pesadez de las colas; el exceso \(> 0\) significa más valores atípicos que una campana
  • Puntaje z — \(z_i = (x_i - \bar{x})/s\), un valor reescalado a “desviaciones estándar respecto a la media”

Para datos económicos sesgados, la mediana suele ser el valor “típico” más honesto.

Acto II · La investigación

Empieza con los números: centro, dispersión, forma

import pandas as pd                          # tabular data
from scipy import stats                      # skewness & kurtosis

# dataset: 171 full-time working women aged 30, 2010 (earnings in $)
url = "https://raw.githubusercontent.com/quarcs-lab/data-open/master/AED/AED_EARNINGS.DTA"
data = pd.read_stata(url)                    # read the Stata .dta into a DataFrame

data[["earnings"]].describe().round(0)       # count, mean, std, min, quartiles, max
stats.skew(data["earnings"]), stats.kurtosis(data["earnings"])  # shape: 1.71, 4.32 (excess)

↗ Pruébalo en Colab

pandas da el centro y la dispersión en una sola llamada; scipy.stats añade la forma. scipy devuelve la curtosis EN EXCESO de forma predeterminada (bruta − 3), así que 0 es la línea base de la campana.

La media queda por encima de la mediana — una señal reveladora de sesgo

  • Media \(= \$41{,}413\) pero mediana \(= \$36{,}000\) — una brecha de $5,413 (15%).
  • Desv. estándar \(= \$25{,}527\) — 62% de la media: una dispersión enorme.
  • \(Q_1 = \$25{,}000\), \(Q_3 = \$49{,}000\) → RIC \(= \$24{,}000\) contiene la mitad central.
  • Asimetría \(= 1.71\) (\(> 1\) = altamente sesgada); curtosis en exceso \(= 4.32\) (colas pesadas).

Un puñado de personas con ingresos altos (máx. $172,000) arrastra la media hacia arriba; reporta la mediana como “típica”.

El diagrama de caja dibuja esas estadísticas en una sola imagen

Caja = \(Q_1\) a \(Q_3\) (el 50% central); línea roja = mediana; puntos a la derecha = valores atípicos de ingresos altos.

La mediana queda a la izquierda del centro y el bigote derecho es largo — el gráfico es el sesgo.

Un histograma muestra toda la distribución — el ancho del bin es una elección

import pandas as pd                          # tabular data
import matplotlib.pyplot as plt               # plotting

url = "https://raw.githubusercontent.com/quarcs-lab/data-open/master/AED/AED_EARNINGS.DTA"
earnings = pd.read_stata(url)["earnings"]    # the single variable

fig, ax = plt.subplots(1, 2, figsize=(12, 5))         # two panels side by side
ax[0].hist(earnings, bins=12, color="#22d3ee", edgecolor="black")  # wider bins → coarse shape
ax[1].hist(earnings, bins=25, color="#22d3ee", edgecolor="black")  # narrower bins → fine detail
plt.show()                                   # render the histograms

Los bins anchos dan la forma; los bins angostos dan el detalle

Los mismos 171 ingresos a dos anchos de bin. Ambos muestran la larga cola derecha; los bins más angostos revelan la agrupación alrededor de $25k–$45k.

Datos categóricos: cuenta, luego muestra las proporciones

import pandas as pd                          # tabular data
import matplotlib.pyplot as plt               # plotting

url = "https://raw.githubusercontent.com/quarcs-lab/data-open/master/AED/AED_FISHING.DTA"
data = pd.read_stata(url)                    # 1,182 recreational fishers

counts = data["mode"].value_counts()         # frequency of each fishing site
counts / counts.sum() * 100                  # relative frequency (% of total)
plt.pie(counts, labels=counts.index, autopct="%1.1f%%")  # each slice = a site's share
plt.show()                                   # render the pie chart

value_counts() construye la tabla de frecuencias; normalize=True (o dividir por la suma) da las frecuencias relativas. Las modalidades en barco (chárter 38% + privado 35%) son ~74% de las elecciones.

La pesca en barco domina las 1,182 elecciones

Chárter (38.2%) + privado (35.4%) = 74% de los pescadores eligen un barco; el muelle y la playa se reparten el resto.

Los gráficos de pastel muestran proporciones; para muchas categorías, un gráfico de barras ordenado las compara de forma más limpia.

Los logaritmos domestican los datos económicos sesgados a la derecha

import numpy as np                           # natural logarithm
import pandas as pd                          # tabular data
from scipy import stats                      # skewness

url = "https://raw.githubusercontent.com/quarcs-lab/data-open/master/AED/AED_EARNINGS.DTA"
data = pd.read_stata(url)                    # load the 171 earnings

data["ln_earnings"] = np.log(data["earnings"])   # log-transform the skewed variable
stats.skew(data["earnings"])                      # 1.71  → strong right skew
stats.skew(data["ln_earnings"])                   # -0.91 → nearly symmetric

↗ Pruébalo en Colab

Los logaritmos convierten los datos multiplicativos y sesgados a la derecha (ingresos, precios, riqueza) hacia la simetría. En la escala log la media (10.46) y la mediana (10.49) casi coinciden. Los logaritmos necesitan datos positivos.

La escala log colapsa la larga cola hacia una campana

Panel A: ingresos en dólares, fuertemente sesgados a la derecha. Panel B: log(ingresos), aproximadamente simétrico — la asimetría baja de 1.71 a −0.91.

Muchas pruebas suponen una forma de campana; la transformación logarítmica es cómo los datos económicos sesgados llegan ahí.

Las series de tiempo necesitan suavizado para revelar la tendencia

import pandas as pd                          # tabular data

url = "https://raw.githubusercontent.com/quarcs-lab/data-open/master/AED/AED_MONTHLYHOMESALES.DTA"
data = pd.read_stata(url).query("year >= 2005")   # monthly U.S. home sales, 2005+
data = data.sort_values("daten")             # ensure time order

data["ma11"] = data["exsales"].rolling(11, center=True).mean()  # 11-month moving average
data[["exsales", "ma11"]].describe().round(0)     # raw (noisy) vs smoothed series

Una media móvil promedia cada punto con sus vecinos, cancelando el ruido mes a mes. El ajuste estacional, en cambio, elimina el patrón recurrente de pico en verano / valle en invierno.

El suavizado revela el colapso inmobiliario de 2007–2011

Las ventas mensuales en bruto zigzaguean con las estaciones; la media móvil de 11 meses (roja) y el ajuste estacional (verde) exponen el ciclo de auge–caída–recuperación.

Una media móvil cancela el ruido estacional; el ajuste estacional elimina el patrón predecible en sí mismo.

Acto III · La resolución

Elige el resumen que coincide con la forma

Objeción. “Simplemente reporta la media y un histograma — eso es un resumen.”

Respuesta. El resumen correcto depende de la forma. Para ingresos sesgados, la media sobreestima el valor “típico”, así que empieza con la mediana y la RIC. La historia de un histograma cambia con su ancho de bin. Y una serie de tiempo en bruto oculta su tendencia hasta que la suavizas.

Ajusta la herramienta a los datos: sesgo → mediana y logaritmos; categorías → barras; tiempo → medias móviles.

Qué llevarte

  • Resume el centro (media/mediana), la dispersión (desv. estándar, RIC) y la forma (asimetría, curtosis).
  • Para datos económicos sesgados, la mediana es el centro honesto; la media es arrastrada por los valores atípicos.
  • Elige el gráfico según el tipo de dato: histograma/caja/línea (numérico), barra/pastel (categórico).
  • Los logaritmos simetrizan los datos sesgados a la derecha; los puntajes z ponen distintas variables en una misma escala.
  • Para series de tiempo, las medias móviles suavizan el ruido y el ajuste estacional elimina los patrones recurrentes.

Resume los números, luego dibuja la forma — y deja que los datos elijan la herramienta.
