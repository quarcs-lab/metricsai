この章は応用を第一に据えます。8.1–8.4節は四つの実際のケーススタディで、いずれも第5–7章と同じ二変量OLS（最小二乗法）回帰で推定されます。ケースごとに変わるのは、データ（国の横断面、月次の金融系列、年次のマクロ系列）、傾きの単位、検定する価値のある仮説、そしてわずかな観測値や誤差の構造が結論をどう変えうるか、という点です。

同じ直線がまったく異なる問いに答える

健康経済学者、ポートフォリオ・マネージャー、マクロ経済学者は別々の世界で働いているように見えます。それでも、各人が手に取るのは同じ道具です。

\[y_i = \beta_1 + \beta_2\, x_i + u_i\]

難しいのは回帰を実行することではありません。傾きを誠実に読むことです。正しい単位で、正しい標準誤差とともに、正しい仮説に照らして、そして傾きを左右しうるわずかな観測値に目を配りながら。

一つの推定量、四つの事件簿。それぞれで、傾きが何を意味するか、どれほど確かか、そして何がそれを誤解を招くものにしうるかを問います。

このスライドデッキを四つの事件簿として位置づけます。それぞれが同じ弧を描きます。問い → データ → 手法 → コード → 出力 → 解釈 → 注意点。繰り返される筋は、あらゆる傾きに対する三部構成のチェックです。(1) 単位、xとyの1単位は何を意味するか。(2) 不確実性、古典的な標準誤差か不均一分散にロバストな標準誤差か。(3) 影響と解釈、どの観測値が傾きを左右するか、そして因果的と言えるか。

横断面：多くの単位を一度だけ観測します。通常の懸念は、誤差分散が単位ごとに異なること（不均一分散）と、わずかな異常な単位が支配すること。時系列：一つの単位を多くの期間にわたって観測します。誤差はしばしば時間にわたって相関し（自己相関）、関係そのものが変化しうる（構造変化）。章は四つのケースすべてで古典的とHC1の標準誤差を報告します。HC1は不均一分散のみに対処します。自己相関する誤差を持つ時系列には、HAC（Newey–West）標準誤差が標準的な対処であり、第13章と第17章に登場します。

手法の復習：二変量回帰のツールキット

推定する

  • 傾き：\(\hat\beta_2 = \dfrac{\sum (x_i-\bar x)(y_i-\bar y)}{\sum (x_i-\bar x)^2}\)
  • 切片：\(\hat\beta_1 = \bar y - \hat\beta_2\,\bar x\)
  • 当てはまり：\(R^2 = r_{xy}^2\)、\(x\)が説明する\(y\)の分散の割合

推測する

  • \(H_0\!: \beta_2 = \beta_2^*\) を \(t = \dfrac{\hat\beta_2 - \beta_2^*}{\text{se}(\hat\beta_2)} \sim t(n-2)\) で検定する
  • 95%信頼区間：\(\hat\beta_2 \pm t_{0.025,\,n-2}\times \text{se}(\hat\beta_2)\)
  • \(\beta_2^* = 0\) は既定値にすぎません。オークンの\(-2\)やCAPMの\(\beta = 1\)の方がより興味深い帰無仮説です

このデッキのすべての結果は、これらの式のいずれかを実データに適用したものです。唯一動く部分は、分母にどの標準誤差が入るかです。

第5–7章の手短な振り返り。二変量回帰ではR²は相関の二乗に等しいので、rの符号と傾きは常に一致します。任意の仮説値β*に対するt統計量は同じ標準誤差を用います。章はいたるところでβ = 0を検定し、暗黙にオークンの法則についてβ = −2を検定します。「この株は市場と同じくらいリスキーか？」が経済学的に興味深い問いなので、CAPMの検定β = 1を加えます。

手法の復習：古典的な標準誤差とロバスト標準誤差

\[\text{古典的: } \widehat{\text{Var}}(\hat\beta_2) = \frac{s^2}{\sum (x_i-\bar x)^2} \qquad \text{HC1: } \widehat{\text{Var}}(\hat\beta_2) = \frac{n}{n-2}\,\frac{\sum (x_i-\bar x)^2\,\hat u_i^2}{\left[\sum (x_i-\bar x)^2\right]^2}\]

  • 古典的なSEは、すべての誤差が同じ分散\(\sigma^2\)を持つ（均一分散）と仮定します
  • HC1は各観測値に固有の\(\hat u_i^2\)を持たせ、その\(x_i\)が\(\bar x\)からどれだけ離れているかで重みづけします
  • したがってHC1は、大きな残差が\(x\)の極端な値にあるとき大きくなり、中央付近にあるときは小さくなりえます
  • 係数は同一です。変わるのはSE、\(t\)、\(p\)、信頼区間だけです

pyfixestではこれは一つの引数です：vcov="HC1"。各ケースで両方を報告し、どこで食い違うかに注目します。

この式はデッキのすべてのSE比較を説明します。8.1では米国が最も極端な支出（高いレバレッジ、大きな(x − x̄)²）と最大の残差の両方を持つため、HC1は古典的SEの1.6–1.7倍になります。8.2では米国とルクセンブルクの両方が平均GDPから遠く、巨大な残差を持つため、HC1は2.3倍になります。8.4では最大の残差が失業率の極端な変化にないため、HC1は古典的SEよりわずかに小さくなります。HC1 = HC0 × n/(n−k)、これは小標本補正であり、Stataの「robust」の既定値です。

五つの考え方がこの章を支える

  • 経済的有意性と統計的有意性：傾きは精密でも小さいことがあり、大きくてもノイズが多いことがあります。両方を報告しましょう

  • 影響力のある観測値：34か国のうち2か国が傾きを41%、\(R^2\)を0.60から0.93まで動かしうる
  • システマティックリスク（\(\beta\)）：資産が市場とともにどれだけ動くか。\(R^2\)はリスクをシステマティックなものと個別のものに分けます
  • 構造変化：59年にわたって推定した関係は漂流しうる。実測値と予測値を時間に沿ってプロットするとそれが明らかになります

ロバストSEが大きい理由：極端な支出での大きな残差

HC1は各残差の二乗を\((x_i-\bar x)^2\)で重みづけします。米国は最も極端に支出する国であると同時に最も当てはまりの悪い国なので、ロバストSEを膨らませます。

手法の復習：ドルの傾きから所得弾力性へ

\[\eta = \frac{\partial\, \text{hlthpc}}{\partial\, \text{gdppc}}\cdot\frac{\overline{\text{gdppc}}}{\overline{\text{hlthpc}}} = 0.0899 \times \frac{33{,}054}{3{,}256} \approx 0.91\]

  • 標本平均では、一人当たりGDPが1%高いと健康支出は約0.91%高くなります
  • 正常財は\(\eta > 0\)を意味します：支出は所得とともに増えます。どんな正の傾きもすでにそう言っています
  • 必需品（\(0 < \eta < 1\)）対贅沢品（\(\eta > 1\)）：支出は比例より少なく、または多く増えます
  • 線形モデルでは弾力性は直線に沿って変化します。平均での評価は一つの評価点です

\(\eta \approx 0.91\)は、この標本では健康支出がおおむね所得に比例して増えることを示しており、必需品と贅沢品の境界に近いところにあります。

章への訂正：章の重要概念8.3は「1.0に近い弾力性は医療が『正常財』であることを示唆する」と述べています。正常財はη > 0を必要とするだけです。ηが1に近いことは単位弾力性（予算に占める割合が一定）を意味します。線形モデルは非ゼロの切片を持つので、弾力性は評価点によって変化します。log-logモデル（第9章）は一定の弾力性を直接推定します。そして次のスライドが示すように、32か国の部分標本に対する同じ計算はη ≈ 1.29、すなわち贅沢品の側を与えます。

  • 小さなN：34観測値では、今見たように2か国がすべての統計量を動かします

「ドルあたり9–13セント」という範囲は、一つを選ぶのではなく両方の推定値を報告します。傾きが直接弾力性となるlog-log定式化が自然な次の一歩であり、まさに第9章が導入するものです。

ケース8.3 · コカ・コーラ株はどれほどリスキーか？

金融時系列 · CAPMベータ · \(\beta = 1\)と\(\alpha = 0\)の検定

ケース8.3：資本資産価格モデル（CAPM）です。ツール：経済理論から導かれる回帰、明確な基準値を持つ傾き（β = 1）、理論的な予測を持つ切片（α = 0）、そしてリスクの分解として読むR²。

理論：市場リスクだけがプレミアムを稼ぐ

\[\underbrace{R_A - R_F}_{\text{資産の超過収益率}} = \alpha_A + \beta_A\,\underbrace{(R_M - R_F)}_{\text{市場の超過収益率}} + u\]

  • \(\beta_A\) = システマティックリスク：資産が市場とともにどれだけ動くか。市場自体は\(\beta = 1\)を持ちます
  • \(\beta > 1\)：攻撃的、市場の変動を増幅します；\(\beta < 1\)：防御的、それを和らげます
  • \(\alpha_A\) = \(\beta\)が正当化する以上の収益率。CAPMは\(\alpha = 0\)を予測します
  • \(u\) = 企業固有の（個別的な）ショックで、分散投資が取り除きます

CAPMは「傾きがゼロである」よりも興味深い二つの仮説を私たちに手渡します：\(\beta = 1\)と\(\alpha = 0\)です。

訂正：章はβ > 1を「成長株」、β < 1を「割安株」とラベルづけします。成長と割安は別の分類であり、簿価対時価のような評価比率に基づきます。成長株が低いベータを持つこともあり、割安株が高いベータを持つこともあります。標準的なベータのラベルは攻撃的（β > 1）と防御的（β < 1）です。実証的なCAPM回帰は金融では「マーケットモデル」または「特性線」と呼ばれます。

データ：354か月の超過収益率、1983年5月 – 2012年10月

rf 1か月物財務省証券金利 0.350% 0.221%

コカ・コーラは市場よりボラティリティが高い（月あたり6.2%対4.6%）のに、CAPMの意味ではよりリスクが低いことが分かります。

変数は小数なので、回帰の傾きは無単位で、切片は月あたりの小数収益率です。標本中で最悪の市場の月は1987年10月（超過収益率−23.1%；コカ・コーラ−15.3%）です。このスライドの一見した逆説はCAPMが解決します。総ボラティリティは個別リスクを含み、それは分散投資で消えます。ベータは市場とともに動く部分だけを測ります。

  • モデルが不完全：他の価格づけされるリスク要因（サイズ、バリュー、モメンタム）が欠けているので、「アルファ」はCAPMが無視するリスクへの報酬です
  • 真のアウトパフォーマンス：コカ・コーラは1983–2012年にわたってリスク調整後の基準を上回りました
  • 事後的な選択：コカ・コーラはうまくいったからこそ有名です。既知の勝者をその勝利の期間にわたって研究すれば、正のアルファが保証されます

一つの選び抜かれた株の一つの有意なアルファは、CAPMに反する弱い証拠です。CAPMの検定は多くの資産を同時に使います。

これらは章の三つの解釈を研ぎ澄ましたものです。三つ目は強調に値します。多くの株を探して最大のアルファを持つものを報告するなら、0.02のp値は何ら注目に値しません。正式なCAPM検定はポートフォリオまたは多くの資産を同時に使います（例：Gibbons–Ross–Shanken検定）。データセットのsmbとhml変数は、多因子モデルが加えるであろうFama–Frenchのサイズとバリューの要因です（第10章以降）。

  • 時間変動するベータ：30年に対する一つのベータは、非常に異なる期間を平均します（0.84対0.44）

  • 市場の代理：時価加重指数が、理論が指す「市場ポートフォリオ」の代わりになります

ケース8.4 · オークンの法則は米国で成り立つか？

  • 失業5% → 6%（+1 pp）：予測成長率は3.0%から\(3.008 - 1.589 \approx\) 1.4%へ下がります
  • 損益分岐点： 成長率が約3.0%のときにのみ失業は横ばいにとどまると予測されます
  • ゼロ成長は\(3.008 / 1.589 \approx\) 1.9 ppの予測される失業の上昇と対応します
  • パーセント対パーセントポイント：成長はパーセントの変化で、説明変数は率の変化なので、その単位はパーセントポイントです

オークンの法則はパーセントポイントについての言明です。「失業が1%上がる」は5%から5.05%を意味し、まったく異なる主張になります。

章の例：「失業が5%から6%（+1ポイント）に上がると、GDP成長率は3%から1.41%に下がる」。3%は切片（失業が変化しないときの成長率）で、正確な値から3.008 − 1.589 = 1.42です。切片の損益分岐点としての読みは古典的なマクロ解釈です。経済は失業を一定に保つためだけに、おおむねトレンド率で成長する必要があります。
