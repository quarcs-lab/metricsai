The question

Act I · The tension

A slope estimate is never the whole story

Chapter 6 gave us a number: each extra square foot is worth about $73.77. But that $73.77 came from just 29 houses — a different 29 would have given a different number.

So the real question isn’t “what is the slope?” — it’s “how much should we trust it?” Inference turns one estimate into a range and a verdict.

The estimate \(b_2 = 73.77\) is a point. Statistical inference attaches uncertainty to that point and lets us test claims about the true population slope \(\beta_2\).

Where we’re going

  • Standard errors — how much the slope jitters from sample to sample
  • The \(t\)-statistic — signal-to-noise ratio for a coefficient
  • Confidence intervals — the range of slopes the data can’t rule out
  • Significance tests — does \(x\) matter at all? (\(H_0: \beta_2 = 0\))
  • Two- and one-sided tests — testing a specific value like $90/sq ft
  • Robust standard errors — valid inference when variance isn’t constant

Six ideas anchor this chapter

  • Null hypothesis \(H_0: \beta_2 = 0\) — the default claim that \(x\) has no effect
  • \(t\)-statistic — \(t = (b_2 - \beta_2^0)/se(b_2)\): distance from the null in SE units
  • Standard error \(se(b_2)\) — the slope’s sampling jitter; shrinks with \(n\), fit, spread in \(x\)
  • Critical value \(t_{n-2,\,\alpha/2}\) — the cutoff that triggers rejection
  • Margin of error \(t_{n-2,\,\alpha/2}\cdot se(b_2)\) — the half-width of the interval
  • Significance — distinguishable from zero given sampling noise (the \(p\)-value, the stars)

Statistical significance is not the same as economic significance — keep both in view.

From estimate to inference

Act II · The investigation

Our case: do bigger houses sell for more — and how sure are we?

29 house sales in Davis, California (1999). We regress price on size:

\[\text{price} = \beta_1 + \beta_2 \cdot \text{size} + u\]

We already have the point estimate \(b_2 = \$73.77\)/sq ft. The rest of the chapter asks how precisely that $73.77 is pinned down — and whether the market could really have \(\beta_2 = 0\).

Step 1 — fit the model and read the full inference table

!pip install -q pyfixest                     # pyfixest isn't preinstalled in Colab (-q = quiet)

import pandas as pd                          # tabular data
import pyfixest as pf                         # OLS with R-style formulas + inference

url = "https://raw.githubusercontent.com/quarcs-lab/data-open/master/AED/AED_HOUSE.DTA"
data = pd.read_stata(url)                    # 29 Davis, CA house sales (price, size, …)

fit = pf.feols("price ~ size", data=data)    # OLS: price on size (intercept auto-added)
fit.summary()                                # coef, se, t, p for b1 (intercept) and b2 (slope)

fit.confint()                                # 95% confidence intervals for each coefficient

↗ Try it in Colab

summary() reports b2 = 73.77, se = 11.17, t = 6.60, p ≈ 0.000. confint() returns [50.84, 96.70] for size. Everything downstream is built from the coefficient and its standard error.

The regression line fits — but the dots scatter around it

Each dot is a house; the line is the OLS fit. The vertical gaps are what size can’t explain — and they drive the standard error.

The slope is $73.77/sq ft. The spread around the line is exactly the uncertainty inference quantifies.

The \(t\)-statistic: how many standard errors from zero?

\[t = \frac{b_2 - \beta_2^0}{se(b_2)} = \frac{73.77 - 0}{11.17} = 6.60\]

  • \(se(b_2) = 11.17\) — the slope would jitter by about $11/sq ft across samples of 29 houses.
  • \(t = 6.60\) — the estimate sits 6.6 standard errors above zero.
  • With \(n - 2 = 27\) degrees of freedom, the 5% cutoff is \(t_{27,\,0.025} = 2.052\).

$6.60 $: the slope is far outside the range noise alone could produce.

Confidence interval: the range the data can’t rule out

\[b_2 \pm t_{27,\,0.025}\cdot se(b_2) = 73.77 \pm 2.052\times 11.17 = [50.84,\ 96.70]\]

pyfixest’s confint() drawn as an error bar: the point estimate with its 95% band.

$0 is nowhere near the interval — but it still spans $46, from $51 to $97 per square foot.

Step 2 — test significance with scipy, by hand

import numpy as np                           # numerics
from scipy import stats                      # t-distribution (preinstalled in Colab)

b2, se2, n = 73.77, 11.17, 29                # slope, its SE, sample size (from the fit)

t_stat = b2 / se2                            # H0: beta2 = 0  ->  t = b2 / se(b2)
df = n - 2                                   # 29 - 2 = 27 degrees of freedom

p_value = 2 * (1 - stats.t.cdf(abs(t_stat), df))   # two-sided p-value
t_crit  = stats.t.ppf(0.975, df)                   # critical value, alpha = 0.05
print(f"t = {t_stat:.2f}, p = {p_value:.4f}, crit = {t_crit:.3f}")

# t = 6.60, p = 0.0000, crit = 2.052  ->  reject H0: size matters

↗ Try it in Colab

pyfixest reports the same p-value automatically; doing it by hand shows the t-statistic, the degrees of freedom, and the critical value are all there is to a significance test.

Testing a specific value: is the slope $90/sq ft?

\[H_0: \beta_2 = 90 \quad\text{vs.}\quad H_a: \beta_2 \neq 90, \qquad t = \frac{73.77 - 90}{11.17} = -1.452\]

  • \(p = \Pr[\,|T_{27}| > 1.452\,] = 0.158 > 0.05\) — do not reject \(H_0\).
  • Equivalently: 90 lies inside the 95% CI \([50.84, 96.70]\).
  • The data are consistent with $90/sq ft — “significant” didn’t mean “equal to zero and nothing else”.

A confidence interval is a whole family of two-sided tests: reject exactly the values outside it.

One-sided tests sharpen a directional claim

Two-sided asks “is it different?”; one-sided asks “is it bigger (or smaller)?”

\[H_0: \beta_2 \le 90 \ \text{vs.}\ H_a: \beta_2 > 90 \qquad\Longrightarrow\qquad p_{\text{one-sided}} = \tfrac{1}{2}\,p_{\text{two-sided}}\]

Put the burden of proof on the direction you must demonstrate — and halve the p-value only when the estimate already points that way.

Step 3 — robust standard errors for honest inference

# classical SEs assume constant error variance (homoskedasticity)

classical = pf.feols("price ~ size", data=data)                 # default (iid) SEs

robust = pf.feols("price ~ size", data=data, vcov="HC1")        # heteroskedasticity-robust
#                                             ^^^^^^^^^^^ matches Stata's "robust"

print(classical.coef()["size"], classical.se()["size"])         # 73.77,  se = 11.17
print(robust.coef()["size"],    robust.se()["size"])            # 73.77,  se = 11.33

# point estimate is unchanged; only the SE (and thus t, p, CI) can move

↗ Try it in Colab

HC1 relaxes the constant-variance assumption. Here the robust SE (11.33) barely differs from the classical one (11.17), so the verdict is unchanged — but with cross-sectional data it’s the safe default.

Residuals look patternless — so the inference holds up

Residuals scattered around zero with no funnel or trend: the model’s assumptions look reasonable here.

Always look at the residuals: a fan shape would warn that robust SEs aren’t optional.

Reading it right

Act III · The resolution

Statistical significance is not economic significance

Objection. “\(t = 6.60\), \(p < 0.001\) — so this is a huge, important result.”

Response. The \(p\)-value only says the effect is distinguishable from zero. Whether $73.77/sq ft matters is an economic judgment — a tiny, precisely-estimated effect can be “significant” yet trivial, and a large effect can be imprecise. Report the magnitude and its interval, not just the stars.

Significance answers “is it there?”; economic significance answers “is it big enough to care?”

What to carry forward

  • The \(t\)-statistic \(t = (b_2 - \beta_2^0)/se(b_2)\) standardizes an estimate against a hypothesis.
  • A 95% CI is \(b_2 \pm t_{n-2,\,\alpha/2}\cdot se(b_2)\) — and it contains every value a two-sided test won’t reject.
  • Significance (\(H_0:\beta_2=0\)) tells you \(x\) matters; it does not tell you how much.
  • Use robust SEs (vcov="HC1") by default for cross-sectional data; check the residual plot.
  • Workflow: fit → read \(se\), \(t\), \(p\) → interval → test → robust check (pyfixest, scipy.stats).

Get the slope, then measure your doubt — a range and a test, not just a number.
