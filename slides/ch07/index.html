One sample, one slope: how much should we trust it?

Act I · The tension

This chapter turns a regression slope into a statement about the population. Chapter 6 gave us the point estimate; Chapter 7 tells us how precise it is, which values of the true slope the data rule out, and how to test claims about it. The same toolkit then gets applied to two real case studies: 108 countries and 333 Bolivian municipalities.

A slope estimate is never the whole story

Chapter 6 gave us a number: in 29 houses sold in Davis, California, each extra square foot goes with $73.77 more in price. A different sample of 29 houses would give a different number.

So the real question is not “what is the slope?” but “how much should we trust it?” Inference turns one estimate into a range (a confidence interval) and a verdict (a hypothesis test).

Every result in this deck answers three questions: Is it precise? Is it real? Does it matter? And a fourth one underneath: is the standard error honest?

The estimate b2 = 73.77 is one draw from a sampling distribution. Inference describes that distribution using only the one sample we have. The four questions are the recurring thread of the deck: precision (SE and CI), statistical significance (tests), economic significance (magnitude in context), and honest uncertainty (classical vs heteroskedasticity-robust SEs). They come back as a scorecard at the end of each part and in the synthesis.

The population model behind every test

\[y_i = \beta_1 + \beta_2 x_i + u_i \qquad\text{estimated by}\qquad \hat y_i = b_1 + b_2 x_i\]

  1. Linearity: the population model is \(y = \beta_1 + \beta_2 x + u\)
  2. Zero conditional mean: \(E[u_i \mid x_i] = 0\)
  3. Constant variance (homoskedasticity): \(\operatorname{Var}[u_i \mid x_i] = \sigma_u^2\)
  4. Independence: \(u_i\) is independent of \(u_j\) for \(i \neq j\)

Assumptions 1–2 make \(b_2\) unbiased. Assumptions 3–4 are what the classical standard error needs; robust SEs (7.7) drop assumption 3.

These are the chapter’s assumptions 1–4. It helps to sort them by what they buy: 1 and 2 are about the coefficient (unbiasedness); 3 and 4 are about its standard error. If 3 fails (heteroskedasticity), the coefficient is still fine but the classical SE is wrong; heteroskedasticity-robust SEs fix that. If 4 fails (clustered or time-series data), we need cluster or HAC SEs, which later chapters use. If 2 fails, no standard error can save the estimate: that is a problem for research design, not inference.

Six ideas anchor this chapter

  • Null hypothesis \(H_0: \beta_2 = 0\): the default claim that \(x\) has no linear effect on \(y\)
  • Standard error \(\operatorname{se}(b_2)\): how much the slope would vary from sample to sample
  • \(t\)-statistic \(t = (b_2 - \beta_2^{*})/\operatorname{se}(b_2)\): distance from the null value in SE units
  • Critical value \(t_{n-2,\,\alpha/2}\): the cutoff that triggers rejection
  • Margin of error \(t_{n-2,\,\alpha/2}\times\operatorname{se}(b_2)\): the half-width of the confidence interval
  • Test of significance: is the coefficient distinguishable from zero, given sampling noise?

Statistical significance is not economic significance. Keep both in view from the first slide to the last.

These are the chapter’s six Key Concepts. Every later slide is built from three numbers: the estimate b2, its standard error, and the degrees of freedom n − 2. The critical value and the margin of error follow from them, and so do the t-statistic, the p-value and the interval.

7.2 · The t-statistic: signal over noise

Standard error of the slope · the \(T(n-2)\) distribution

Section 7.2: the standard error of the slope, what makes it large or small, and the t-statistic that standardizes the estimate.

The slope is a random variable

  • Population: \(E[y \mid x] = \beta_1 + \beta_2 x\), with unknown \(\beta_2\)
  • Sample: OLS gives \(b_2 = 73.77\), one draw from the sampling distribution of \(b_2\)
  • Under assumptions 1–4: \(\;E[b_2] = \beta_2\) and \(\operatorname{Var}[b_2] = \dfrac{\sigma_u^2}{\sum_{i=1}^{n}(x_i - \bar x)^2}\)
  • We never know \(\sigma_u^2\), so we replace it with \(s_e^2 = \dfrac{1}{n-2}\sum_{i=1}^{n}(y_i - \hat y_i)^2\)

\[\operatorname{se}(b_2) = \frac{s_e}{\sqrt{\sum_{i=1}^{n}(x_i - \bar x)^2}}\]

Standard deviation describes the spread of the data; standard error describes the spread of the estimate across samples.

The key distinction: SD is a property of the observations, SE is a property of the estimator. The variance formula is the classical one, valid under homoskedasticity and independence. We divide by n − 2 because two parameters (intercept and slope) were estimated from the same data, which uses up two degrees of freedom.

Three knobs set the standard error

\[\operatorname{se}(b_2) = \frac{s_e}{\sqrt{\sum (x_i - \bar x)^2}} \approx \frac{s_e}{\sqrt{n}\;s_x}\]

Knob Turn it up Effect on \(\operatorname{se}(b_2)\)
Residual spread \(s_e\) worse fit, more noise larger
Sample size \(n\) more houses smaller, at rate \(1/\sqrt n\): quadruple \(n\) to halve the SE
Spread of \(x\), \(s_x\) wider range of sizes smaller: extreme \(x\) values pin down the slope

A precise slope needs a tight fit, many observations and a wide spread in \(x\). All three are design choices, not luck.

The seesaw intuition from the chapter: the line pivots around the point of means. If the x values are spread widely, a small change in slope makes a big difference at the ends, so the data pin the slope down. If x values are bunched together, many slopes fit almost equally well. The approximation with √n·s_x is the chapter’s shortcut; the exact denominator is √(n−1)·s_x when s_x uses n − 1.

Code: build the standard error by hand

!pip install -q pyfixest                     # pyfixest is not preinstalled in Colab
import numpy as np                           # square roots and sums
import pandas as pd                          # tabular data
import pyfixest as pf                        # OLS with R-style formulas
url = "https://raw.githubusercontent.com/quarcs-lab/data-open/master/AED/AED_HOUSE.DTA"
data_house = pd.read_stata(url); model_basic = pf.feols("price ~ size", data=data_house)
n = len(data_house)                          # 29 houses
e = model_basic.resid()                      # residuals y - y_hat
s_e = np.sqrt((e**2).sum() / (n - 2))        # standard error of the regression
x = data_house["size"]                       # the regressor
sxx = ((x - x.mean())**2).sum()              # total variation in x
se_formula = s_e / np.sqrt(sxx)              # classical se(b2), exact
se_shortcut = s_e / (np.sqrt(n) * x.std())   # chapter's shortcut with sqrt(n)
print(s_e, np.sqrt(sxx), se_formula, se_shortcut, model_basic.se()["size"])

The \(t\)-statistic standardizes the estimate

\[t = \frac{b_2 - \beta_2^{*}}{\operatorname{se}(b_2)} \;\sim\; T(n-2) \quad\text{under } H_0: \beta_2 = \beta_2^{*}\]

  • If we knew \(\sigma_u\), the ratio would be standard normal, \(N(0,1)\)
  • Estimating \(\sigma_u\) by \(s_e\) adds extra uncertainty, so the ratio follows Student’s \(t\) with \(n - 2\) degrees of freedom
  • For \(H_0: \beta_2 = 0\): \(\;t = \dfrac{73.77}{11.17} = 6.60\)

\(t = 6.60\) means the slope sits 6.6 of its own standard errors above zero.

Degrees of freedom: 29 observations minus 2 estimated parameters = 27. This is the bivariate counterpart of the univariate t-statistic from Chapter 4, (x̄ − μ)/se(x̄) ~ T(n − 1). The only difference is that one more parameter is estimated, so one more degree of freedom is used up.

7.3 · Confidence intervals: the slopes the data cannot rule out

Estimate ± critical value × standard error

Section 7.3: building, computing and correctly interpreting a confidence interval for the slope, and why the t-distribution rather than the normal.

A confidence interval is estimate ± margin of error

\[b_2 \;\pm\; t_{n-2,\,\alpha/2}\times\operatorname{se}(b_2)\]

\[73.77 \;\pm\; 2.052 \times 11.17 \;=\; 73.77 \pm 22.93 \;=\; [50.84,\ 96.70]\]

  • \(t_{27,\,0.025} = 2.052\): the value that leaves 2.5% in each tail of \(T(27)\)
  • Margin of error 22.93: the half-width of the interval
  • Quick approximation: \(b_2 \pm 2\times\operatorname{se}(b_2)\)

The interval spans $46 per square foot: size clearly matters, but its price is pinned down only to “somewhere between $51 and $97”.

The general recipe from Chapter 4 carries over: estimate ± critical value × standard error. With 27 degrees of freedom the 95% critical value is 2.052 rather than 1.96. The width, 2 × 22.93 = 45.86 dollars, is the honest summary of how much 29 houses can tell us.

What “95% confidence” does and does not mean

  • Wrong: “there is a 95% probability that \(\beta_2\) lies between 50.84 and 96.70”
  • Right: if we drew many samples and built an interval from each, about 95% of those intervals would contain \(\beta_2\)
  • \(\beta_2\) is a fixed number; the interval is what varies from sample to sample
  • Our interval [50.84, 96.70] either contains \(\beta_2\) or it does not; 95% describes the procedure’s long-run success rate

Width depends on three things: the confidence level, the sample size (through both the SE and the critical value) and the residual noise.

This is the chapter’s Key Concept 7.2. The frequentist interpretation is subtle, and the wrong version is very common, even in published work. A useful way to say it in words: “the procedure that produced this interval captures the true slope 95% of the time”. The next slide makes the idea visible with a simulation.

7.4 · Is the slope different from zero?

Tests of statistical significance · \(p\)-values · economic significance

Section 7.4: the test of statistical significance, the p-value and the critical-value rules, and the crucial difference between statistical and economic significance.

The test of statistical significance

\[H_0: \beta_2 = 0 \qquad\text{vs.}\qquad H_a: \beta_2 \neq 0, \qquad t = \frac{b_2}{\operatorname{se}(b_2)} \sim T(n-2) \text{ under } H_0\]

  • \(p\)-value rule: reject \(H_0\) at level \(\alpha\) if \(p = \Pr\big[\,|T_{n-2}| > |t|\,\big] < \alpha\)
  • Critical-value rule: reject \(H_0\) if \(|t| > t_{n-2,\,\alpha/2}\)
  • The two rules always agree; \(\alpha\) is the probability of a Type I error (rejecting a true \(H_0\))
  • Never “accept” \(H_0\): we either reject it or fail to reject it

A regressor “matters” statistically when its coefficient is too far from zero to blame on sampling noise.

The five-step workflow from Key Concept 7.3: state H0 and Ha, choose α (usually 0.05), compute the test statistic, find the p-value, decide, and then translate the decision into plain language. The null is the claim we try to overturn; the burden of proof is on the data.

Code: run the test both ways

!pip install -q pyfixest                     # pyfixest is not preinstalled in Colab

print(t_stat_size, p_value_size, t_crit)
print("Reject H0" if p_value_size < 0.05 else "Fail to reject H0")

Statistically significant does not mean important

Statistical significance

  • Is the effect distinguishable from zero?
  • Driven by \(t = b_2/\operatorname{se}(b_2)\), so by \(n\), noise and spread in \(x\)
  • With a huge \(n\), even a trivial effect is “significant”

Economic significance

  • Is the effect large enough to matter?
  • Driven by the magnitude of \(b_2\), in context
  • Needs domain knowledge, not a table of critical values

Report the magnitude and its confidence interval, not just the stars. The interval answers both questions at once.

Key Concept 7.4. Two failure modes: a precisely estimated but tiny effect (statistically significant, economically trivial), and a large but imprecise effect (economically important, statistically insignificant). 7.5 · Is the slope $90 per square foot?

Two-sided tests of a specific value · the CI–test duality

Section 7.5: testing whether the slope equals a specific non-zero value, and why that is the same as asking whether the value lies inside the confidence interval.

Testing a specific value: same recipe, new null

\[H_0: \beta_2 = 90 \qquad\text{vs.}\qquad H_a: \beta_2 \neq 90\]

\[t = \frac{b_2 - 90}{\operatorname{se}(b_2)} = \frac{73.77 - 90}{11.17} = -1.452\]

  • Two-sided \(p = \Pr\big[\,|T_{27}| > 1.452\,\big]\)
  • Reject at 5% only if \(|t| > 2.052\)
  • Where could 90 come from? A realtor’s rule of thumb, a building-cost benchmark, a previous study

Only the numerator changes: the test asks how many standard errors the estimate is from the claimed value.

The test of significance is the special case β2* = 0. Any economically interesting benchmark can be tested the same way. The sign of t tells you which side of the claim the estimate falls on: here the estimate is 16.23 dollars below 90.

Code: test \(H_0: \beta_2 = 90\)

If the true slope were 90, an estimate at least 16.23 dollars away from 90 (in either direction) would occur in about 16% of samples, which is not unusual. The figure puts the two tests side by side on the same T(27) density: the test of zero rejects overwhelmingly, the test of 90 does not.

A confidence interval is a family of tests

  • Reject \(H_0: \beta_2 = \beta_2^{*}\) at 5% exactly when \(\beta_2^{*}\) is outside the 95% CI
  • 0 is outside [50.84, 96.70] → reject; 90 is inside → do not reject
  • But 60, 75 and 95 are inside too: the data are consistent with all of them
  • “Do not reject \(\beta_2 = 90\)” does not mean “\(\beta_2 = 90\)”

Failing to reject is a statement about the data’s power, not proof of the null. Report the interval and every plausible value is visible at once.

Key takeaway 4 of the chapter. The duality makes confidence intervals more informative than a single test: one interval answers every two-sided test at once. A common mistake is to read “fail to reject” as “accept”: with 29 houses the data cannot distinguish 90 from 60. Key Concept 7.9: never conclude “proved β2 = 90”.

7.6 · Is the slope less than $90?

One-sided directional tests

Section 7.6: directional hypotheses, where the rejection region sits in only one tail, and the conditions under which the two-sided p-value can be halved.

One-sided tests put the claim in the alternative

Test \(H_0\) \(H_a\) (the claim) Reject when \(p\)-value
Upper tail \(\beta_2 \le \beta_2^{*}\) \(\beta_2 > \beta_2^{*}\) \(t > t_{n-2,\,\alpha}\) \(\Pr[T_{n-2} > t]\)
Lower tail \(\beta_2 \ge \beta_2^{*}\) \(\beta_2 < \beta_2^{*}\) \(t < -t_{n-2,\,\alpha}\) \(\Pr[T_{n-2} < t]\)
  • The claim you want to demonstrate goes in \(H_a\), so the data must prove it
  • The whole 5% sits in one tail: \(t_{27,\,0.05} = 1.703\) instead of 2.052
  • Choose the direction before seeing the data, from theory

A one-sided test has more power in the predicted direction, and none at all in the other.

Key Concept 7.5. One-sided tests are appropriate when theory predicts the direction and you only care about deviations in that direction. Journals usually expect two-sided tests, partly because choosing the direction after looking at the estimate is a form of fishing.

Code: both one-sided tests of 90

!pip install -q pyfixest                     # pyfixest is not preinstalled in Colab

Halve the \(p\)-value only when the estimate points your way

  • Software reports two-sided \(p\)-values for \(H_0: \beta_2 = 0\)
  • One-sided test of significance: if \(b_2\) has the predicted sign, one-sided \(p\) = two-sided \(p\) / 2
  • If \(b_2\) has the wrong sign, one-sided \(p > 0.5\): rejection is impossible
  • House example: \(H_a: \beta_2 > 0\) gives \(p = 2.2\times 10^{-7}\), half of \(4.4\times 10^{-7}\)

An earlier version of this deck halved the \(p\)-value for \(H_a: \beta_2 > 90\). That is wrong: with \(b_2 = 73.77 < 90\) the correct one-sided \(p\) is 0.921.

The halving rule has a condition attached, and dropping the condition is a common slip. The chapter states it correctly (“if sign is correct”) and its code computes both tails. Practical advice: decide the direction from theory before estimation, and when in doubt report the two-sided test.

7.7 · Are the standard errors honest?

Heteroskedasticity · HC1 robust standard errors · residual diagnostics

Section 7.7: what happens to inference when the error variance is not constant, and how heteroskedasticity-robust standard errors fix it.

Heteroskedasticity breaks the classical standard error

Assumption 3 says \(\operatorname{Var}[u_i \mid x_i] = \sigma_u^2\) for every observation. Heteroskedasticity: \(\operatorname{Var}[u_i \mid x_i] = \sigma_i^2\) varies with \(i\).

What Under heteroskedasticity
Coefficient \(b_2\) still unbiased and consistent
Classical \(\operatorname{se}(b_2)\) wrong, too small or too large
\(t\), \(p\), confidence intervals invalid (wrong size, wrong coverage)

The fix leaves the estimate alone and repairs the uncertainty: a heteroskedasticity-robust standard error.

Heteroskedasticity is common in cross-sections: spending varies more among rich households, sales vary more among large firms, house prices vary more among large houses. The direction of the bias in the classical SE depends on the pattern, so we cannot predict it without knowing the form. Robust SEs are valid whether or not heteroskedasticity is present.

Classical vs robust: one formula, one change

\[\operatorname{se}(b_2) = \frac{s_e}{\sqrt{\sum (x_i - \bar x)^2}} \qquad\qquad \operatorname{se}_{\text{HC0}}(b_2) = \frac{\sqrt{\sum e_i^2\,(x_i - \bar x)^2}}{\sum (x_i - \bar x)^2}\]

  • Classical: one pooled residual variance \(s_e^2\) for every observation
  • Robust (White / Huber–White): each squared residual \(e_i^2\) is weighted by that observation’s leverage \((x_i - \bar x)^2\)
  • HC1 = HC0 × \(\sqrt{n/(n-k)}\), a degrees-of-freedom correction; with \(n = 29\), \(k = 2\) the factor is 1.036
  • Variants: HC2 (leverage-weighted), HC3 (more conservative); HAC for time series, cluster-robust for grouped data

The chapter prints the HC0 formula (10.93 for the house slope), but its code and tables use HC1 (vcov="HC1", 11.33), which matches Stata’s robust.

Large residuals at extreme x values are exactly what the classical formula misses. HC1 multiplies the HC0 variance by n/(n − k); for the house data, HC0 = 10.932 and HC1 = 10.932 × √(29/27) = 11.330. This deck labels the formula as HC0 and reports HC1 numbers, so the two are not confused.

Best practice: decide on the SE before you look at the results

  • Cross-section: heteroskedasticity-robust (vcov="HC1") by default
  • Time series: HAC (Newey–West) SEs; grouped data: cluster-robust SEs
  • Do not pre-test for heteroskedasticity and then choose; just use robust SEs
  • Never switch between classical and robust SEs to obtain significance: that is \(p\)-hacking
  • If robust SEs are much larger than classical ones, investigate the model, not just the SE

Seven misreadings to avoid

  1. “95% chance \(\beta_2\) is in the interval”: no, 95% of intervals cover \(\beta_2\)
  2. “\(p < 0.001\), so the effect is large”: \(p\) measures evidence against \(H_0\), not size
  3. “We fail to reject, so \(\beta_2 = 90\)”: the data are also consistent with 60 and 95
  4. “Halve the \(p\)-value for any one-sided test”: only when the estimate points toward \(H_a\)
  5. “Robust SEs only when a test finds heteroskedasticity”: use them by default
  6. “Split the sample by the outcome to compare slopes”: that truncates \(y\) and biases both slopes
  7. “Significant, so causal”: every slope in this deck is an association

Each one is a real trap, and each has a slide in this deck that shows the correct reading with the chapter’s own numbers.

The tempting shortcut, and the correction

Objection. “\(t = 17.9\), \(p < 0.001\), \(R^2 = 0.87\): capital clearly drives productivity, and we know the effect to the third decimal.”

Response. The classical SE overstated precision by 48%, the residuals fan out and curve, the sample split biased the group slopes, and nothing in a cross-section of levels identifies a causal effect. Significance tells you the association is not noise. It does not tell you how big it is, how precise it truly is, or why it exists.

Read every regression table with four questions: how big, how precise (with an honest SE), how plausible are the alternatives, and what would make it causal.

Steelman the objection: the association really is strong and robust to the SE choice. But every adjective in the objection overreaches: “drives” is causal, “know to the third decimal” ignores the 48% understatement of uncertainty. Chapters 10–13 add controls, and Chapter 13 adds research designs, precisely because significance cannot answer the “why”.

What to carry forward

  • \(t = (b_2 - \beta_2^{*})/\operatorname{se}(b_2) \sim T(n-2)\): every test is “estimate minus claim, in SE units”
  • A 95% CI is \(b_2 \pm t_{n-2,\,0.025}\,\operatorname{se}(b_2)\) and contains every value a two-sided 5% test does not reject
  • \(\operatorname{se}(b_2)\) shrinks with a tighter fit, more data (\(1/\sqrt n\)) and more spread in \(x\)
  • One-sided tests: the claim goes in \(H_a\), the direction is fixed in advance, halving needs the right sign
  • Cross-sections: vcov="HC1" by default; look at the residuals; a large gap signals a model problem
  • Always report magnitude and precision; significance is not importance, and association is not causation
