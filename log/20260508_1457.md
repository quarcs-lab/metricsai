- Each entry is a bold term with a 1–2 sentence definition, plus two side-by-side collapsible Quarto callouts:

### Colab strip — `scripts/export_qmd_to_ipynb.py`
- New function `strip_key_concepts(text)` removes the entire `## Key Concepts ... (until the next `## ` heading)` block from every Markdown cell during `.qmd → .ipynb` conversion.
- Reason: Quarto callouts and `:::: {.columns}` markup don't render in Colab. Stripping at conversion time keeps Colab notebooks clean while preserving the section in the HTML book and `.md` mirror.
- Verified by `verify_section.py`: 0 hits for `## Key Concepts`, `callout-tip`, `callout-note`, `::::: {.columns}`, `:::: {.column` in any synced `.ipynb`.

## Decisions Made
- **Additive, not duplicative**: each chapter's pre-existing inline `> Key Concept N.M` blockquotes were left untouched. The new section's concepts are *disjoint* from those titles (subtraction by normalised term), filling pedagogical gaps rather than restating known material.
- **Strip from Colab, keep in book**: Colab readers see clean code-first notebooks; book readers see the glossary up-front. Single source `.qmd`, two distinct downstream presentations.
- **Glossary, not content**: section heading is `## Key Concepts` (no number), placed *before* `## Setup` so readers can browse it without context.
- **Pedagogical rubric is non-negotiable**: every example references the chapter's actual dataset and at least one real variable name; every analogy comes from a domain not used by any sibling concept in the same chapter; every concept maps to a specific `**What you'll learn:**` bullet.
- **Fully-autonomous one-shot skill**: per the user's stated preference, the skill drafts + inserts + syncs + verifies in a single run, with no interactive content checkpoints.
