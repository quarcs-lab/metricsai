# 2026-05-15 13:00 — i18n infrastructure refactor: Phase 2 shipped

## Goal

Phase 2 of the multi-language refactor (plan: `~/.claude/plans/in-the-navigation-bar-crystalline-castle.md`). Extract every i18n key that is identical across two or more pages into shared string files, so chapter templates and the two top-level pages will load them via `<script src>` instead of inlining duplicate dicts. **No HTML touched in this phase** — Phase 3 (`index.html` + `tutors.html`) and Phase 4 (17 chapter migration script) will rewire references.

## Source-of-truth decisions

- ch01 was used as the canonical source for shared values. Spot-checked against ch10 and ch17 — every shared key matches when ch17's `ó` escapes are decoded. ch01 is the cleanest reference (hand-prototyped) and predates the navbar migration script.
- For ES values, this run did not introduce any vocabulary changes. The three normalizations from the previous session (`heterocedasticidad`, `FAC`, `VI`) were already applied across all chapters and were confirmed clean during ch01 extraction. `canonical-terms.md` remains the authoritative reference for Phase 4.

## What's NOT yet done

Then run each chapter's `build.py` to regenerate `dashboard.html`.
- **Phase 5** — Verify zero EN/ES regression: `i18n_check.py` clean; smoke test 3 random chapters in browser; confirm cross-page persistence (set ES on `index.html`, navigate to `web-apps/ch08/dashboard.html`, expect ES boot).
