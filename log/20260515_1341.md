## What shipped

### `scripts/migrate_to_shared_i18n.py` (NEW, ~350 lines, idempotent)

One-shot migration script. For each `web-apps/chNN/template.html`:

- Detects the `(?:const|var)\s+I18N\s*=\s*\{...\}` block via balanced-brace scanning that respects strings + line comments.
- Extracts every `(key, en_value, es_value)` triple from the `en: {...}` and `es: {...}` sub-blocks.
- **Decodes unicode escapes** (`\\u00ed → í`) so the new chXX.js files store direct UTF-8 (matters for ch13/ch17 which had ~130–150 escaped chars each).
- **Drops 27 shared keys per chapter** (the canonical Phase-2 set):
  - 11 from `nav.js` (nav.about, nav.notebooks, nav.tutors, nav.books, nav.videos, nav.podcasts, nav.authors, nav.resources, nav.cameron.pre, nav.cameron.cta, nav.code)
  - 5 from `common.js` (common.howtoTitle, common.tryTitle, common.reset, theme.dark, theme.light)
  - 10 from `code.js` (code.heading, code.motivation, code.tab.python, etc.)
  - 1 (`header.title`) collapsed into `chapter.chNN.title` (canonical)
- **Logs divergence warnings** when a chapter's value for a shared key differs from canonical (ch01) — uses canonical, doesn't preserve drift.
- **Writes `web-apps/_shared/strings/chXX.js`** with the remaining ~110–200 chapter-specific keys.
- **Patches `template.html`:**
  - Inserts the 7 shared `<script src="../_shared/...">` tags (config + runtime + 4 shared strings + chXX.js) BEFORE the inline `<script>` block.
  - Deletes the entire `(const|var) I18N = {...};` block + `function t(...)` + `function applyLanguage(...)` + `function toggleLanguage()` + boot try/catch IIFE.
  - Replaces with a single one-line marker comment.
  - Rewrites `data-i18n="header.title"` → `data-i18n="chapter.chNN.title"`.
- **Regenerates `dashboard.html`** by invoking `web-apps/chNN/build.py` afterwards.

Idempotency: detects `<script src="../_shared/i18n-runtime.js"` in template, skips if found. Re-running is safe.

### `scripts/i18n_check.py` — three additions

The validator gained false-positive resilience for the post-Phase-4 reality:

1. **Page-exclusive duplicate exemption.** `chXX.js`, `index.js`, and `tutors.js` are mutually exclusive at runtime (only one ever loads per page). Duplicate keys among them no longer fail the check. Shared files (`nav.js`/`common.js`/`code.js`/`chapter-titles.js`) still must be unique.
2. **Dynamic-prefix tolerance.** Keys ending in `.` (from patterns like `t("var.label." + name)`) are no longer flagged as undefined references — they're prefixes, not full keys.
3. **Indirect string-literal scan.** Any string literal in HTML/JS that EXACTLY matches a defined i18n key is counted as referenced (catches patterns like `t(skKey)` where `skKey = "common.highSkewed"`). Eliminated 40+ false-positive orphans.
