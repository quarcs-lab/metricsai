# 2026-10-16 — Google Translate button on chapter quizzes

## Current state

All 17 quizzes (`quizzes/ch01–ch17.html`) have a globe button in the header, next to dark mode. It machine-translates the whole quiz to Español or 日本語 via a hidden Google Translate element. Changes are in `quizzes/_template.html` only, and every quiz was rebuilt with `scripts/build_quiz.py`. Not committed.

## Decisions (confirmed with user)

- The control is a custom globe menu offering only EN / ES / JA. It does not use Google's stock widget.
- On load, the quiz uses its own `localStorage.quizLanguage` if set. Otherwise it follows the website's `localStorage.language`. The quiz never writes `language`.
- Translation applies in both Practice and Exam. Certificate, report/print area, student name, timer, option letters, KaTeX math and the brand name stay English (`notranslate` / `translate="no"`).
- A slim notice is shown while ES/JA is active: "Machine translation by Google. The English version is authoritative." The notice itself gets translated.
- Google's `googtrans` cookie is shared with the online book. The quiz restores the cookie's prior value after each switch, so the book's language choice is unaffected.

## Key finding

Google Translate did NOT pick up text the quiz rendered after its first pass: question stems, feedback, results, modal. Testing ruled out the 250 ms timer, scroll/lazy loading, and the `lang` attribute; the root cause was not identified. Fix: the engine calls `retranslate()` (→ `window.quizRetranslate`, debounced 200 ms) from `typeset`, `showScreen`, `updateStart`, `updateBar`, `openModal`, `toast` and `announce`. The controller then runs "Show original" (the restore button in Google's hidden banner iframe) followed by the active language. With cached strings this takes about 0.2 s.

## Verification

- Playwright over `python3 -m http.server`: ES/JA/EN switching, auto-apply from the site key, cookie restore, a full Spanish Practice run, a passing Exam with an English certificate, Japanese math (ch06 Q18), dark mode, the 375 px menu, and no console errors.
- Existing suite: `.claude/skills/write-quiz/scripts/test_quiz.py chNN` for all 17 chapters (results in the session report).
