## The 11 transforms (encoded in the migration script)

The script applies each transformation to `template.html` in sequence. Each is idempotent (running again is a no-op).

1. Insert Font Awesome 6.4.0 CDN `<link>` after the Google Fonts link.
2. Add `padding-top: 64px;` to the `body{}` rule (room for the fixed navbar).
3. Inject the `.site-nav*` CSS block before the `code, .mono { ... }` rule (anchor that exists in every chapter).
4. Insert the `<nav class="site-nav">` markup + `<div class="site-nav-mobile">` drawer right after the `<body>` tag.
5. Delete the chapter header's `<div class="header-controls">…</div>` block (held the old language + theme buttons).
6. Delete the now-orphaned `.header-controls`, `.theme-toggle`, `.theme-toggle:hover` CSS rules.
7. Rename `const|var THEME_KEY = "metricsai-theme"` → `const THEME_KEY = "darkMode"` (unified key shared with `index.html` / `tutors.html`).
8. Replace the entire THEME TOGGLE IIFE with the new `applyDarkMode` / `toggleDarkModeNav` + auto-init IIFE, and append the `toggleSiteMobileMenu` function.
9. Rewire `applyLanguage`: `getElementById("languageLabel")` → `getElementById("siteLanguageLabel")`.
10. Remove the dead `__themeLabelRefresh` call block inside `applyLanguage`.
11. Insert 10 site-nav i18n keys (`nav.about`, `nav.notebooks`, `nav.tutors`, `nav.books`, `nav.videos`, `nav.podcasts`, `nav.authors`, `nav.resources`, `nav.cameron.pre`, `nav.cameron.cta`) before each chapter's `"common.reset":` entry in BOTH `I18N.en` and `I18N.es` (English + Spanish translations).

## Variability handled by the script

The chapters fall into three minification styles:

- **Pretty-printed** (ch01, ch02, ch03, ch08): one CSS rule per line, IIFEs spread across many lines.
- **Mixed minification** (ch04, ch05, ch06, ch07, ch09, ch10, ch12, ch16): some IIFEs minified, others not; body rule on a single line.
- **Heavily minified** (ch11, ch13, ch14, ch15, ch17): multiple CSS rules concatenated on a single line; theme IIFE compressed to one line; `const THEME_KEY="metricsai-theme"` with no spaces.

Two regex traps the first cut missed (both flagged loudly by the script's assertions, no silent corruption):

- **Body rule with no trailing semicolon** (`color .25s ease}` instead of `color .25s ease;}`): the first version of `add_body_padding` looked for `color .25s ease;` and failed on 6 chapters. Fixed by anchoring the injection at the END of the `body{...}` block instead — the leading `;` in the injected text safely separates from whatever came before.
- **Theme comment header variation**: some chapters say `// ==== THEME TOGGLE ====`, ch17 says `// ==== THEME ====`. Regex is `// =+\s*THEME(?: TOGGLE)?\s*=+`.

2. **Patch the skill scaffold** at `.claude/skills/web-app/templates/base.html` so future scaffolded chapters inherit the navbar already. (NOT done today — deferred.)
