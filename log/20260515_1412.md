### 5.3 Headless browser smoke (Playwright)

Installed `playwright install chromium` (one-time, ~266 MB to `~/Library/Caches/ms-playwright/`). Wrote `scripts/smoke_i18n.py` (~210 lines) that:

1. Spins up `python3 -m http.server 8123` in the repo root so `localStorage` is shared across pages (file:// would isolate per-path on Chromium).
2. For each of `ch04`, `ch10`, `ch16`:
   - Loads `web-apps/<ch>/dashboard.html`, waits for `window.I18N` populated.
   - Snapshot 1 (EN): `documentElement.lang`, `#siteLanguageLabel`, `document.title`, 5 `[data-i18n]` element texts (`chapter.<ch>.title`, `header.badge`, `nav.about`, `common.howtoTitle`, `code.heading`), and one Plotly tick label.
   - `window.toggleLanguage()` → 400 ms wait → Snapshot 2 (ES). Assert lang flipped, label flipped, title differs, all 5 `[data-i18n]` differ.
   - Scan `body.innerText` for any defined-key string (regex `\b[a-z][\w]*\.[a-z][\w.]*\b` against the validator's 2,420-key set, ignoring code-context tokens like `np.random` or `*.py`). **Zero leaks** on any chapter.
   - Toggle again → Snapshot 3 (EN'). Assert exact equality with Snapshot 1.
