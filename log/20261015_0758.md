# Homepage visual-summary language switching

## Current state

The Spanish and Japanese image files were committed in b89526c, but homepage
chapter cards still had fixed English sources. The live site reproduced the
reported issue: its text changed to Japanese while all 17 image sources stayed
English.

## Work done

- Added the homepage `__rerender_visualSummaries` handler to the existing shared
  language-renderer registry. It preserves each English source and selects the
  corresponding `_es.png` or `_ja.png` image on switching and persisted boot.
- Image enlargement already uses the thumbnail's current source, so it now
  opens the same localized version.
- Extended the existing i18n smoke suite to exercise all 17 chapters through
  EN/ES/JA/EN, reloads, the enlarged image, and the mobile picker.
- Added a project lesson about verifying asset integration before reporting
  localization complete.

## Validation

- Verified actual Spanish/Japanese full-size PNG decoding with Chromium;
