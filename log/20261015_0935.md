# 2026-10-15 09:35 — Chapter 1 interactive quiz (prototype)

## Current state

A self-hosted, interactive Chapter 1 quiz exists as a **prototype for review**. It is **not linked** from the website yet; the edcafe.ai "Quiz" links in `index.html` and the ch01 `.qmd` are unchanged. Nothing is committed.

## Work done

- **`quizzes/_template.html`**: a quiz engine that works for any chapter (vanilla HTML/CSS/JS, metricsAI brand, light/dark mode via the site-wide `localStorage.darkMode` key, no site navbar). Chapter, title, minutes and pass mark all come from the bank's `meta`.
- **`quizzes/banks/ch01.json`**: a readable question bank, 30 Practice + 30 Exam items.
  - Formats: single-answer, select-all (scored all-or-nothing), and true/false.
  - Every option has its own feedback, and every item has a key-idea explanation.
- **`scripts/build_quiz.py`**: validates the bank and builds the quiz.
  - Checks: item counts, unique ids, no duplicate stems, correct-option counts per type, non-empty feedback, no `<script`.
  - Prints the type mix and the spread of correct-option positions.
  - Writes `quizzes/chNN.html` with the bank inlined as base64. This deters casual peeking at the key; it is not security.
- **`quizzes/ch01.html`**: the built, self-contained deliverable (~172 KB).
- **Two new lessons in CLAUDE.md:** verify dataset claims against the data; keep key-hidden exam feedback from stating the correction.

## Decisions (from the user Q&A, 8 rounds)

- **Modes:** Practice and Exam, each with its own fixed set of 30 questions in a fixed order (options are not shuffled).
- **Timer:** 45-minute countdown in both modes, auto-submit at zero.
- **Exam navigation:** free, with a question navigator and flag-for-review.
- **Feedback:**
  - Practice: rich feedback after each question.
  - Exam below 80%: concept feedback on missed items only, never the key. The key leaks on true/false items, which the user accepted.
  - Exam at 80% or above: full key plus a certificate.
- **Results file:** print to PDF, which the student uploads to the LMS.
  - Passed: a one-page landscape certificate (metricsAI branding only, no signature, no ID).
  - Not passed: a one-page portrait summary report.
  - Neither ever includes questions or answers. There is no topic breakdown.
- **Identity and retakes:** name only; unlimited retakes; attempt number counted per browser.
- **Content:** English only. Concepts and interpretation only (no Python code, no case studies), with an application-heavy difficulty mix.
- **Extras:** progress bar, counters, and confetti. The user declined confidence ratings, hints, book links, resume-after-close, and a tab-switch log.

## Quality checks

- **Fact check:** every number in the bank was verified against `data/AED_HOUSE.DTA` using exact pyfixest values (34/34). Script: scratchpad `factcheck_ch01.py`.
- **Two adversarial review rounds** by a subagent. No wrong keys were found. Fixes:
  - Exam wrong-option feedback that revealed the key.
  - An alternating A,C / B,D pattern on select-all keys.
  - Correct options that were the longest or most hedged.
  - Concept labels that named the answer.
  - Copies between Practice and Exam items.
  - The E21 p-value wording.
  - Serial commas, to match the chapter's style.
- **Data contradictions caught:**
  - House age is barely related to size (r = 0.08) or price (r = −0.07), so the "age" option was removed from the omitted-variable item.
  - AED_HOUSE rows are sorted by price (row order correlates 0.88 with price), so "row order" can't be used as a distractor that is unrelated to both size and price.
- **Playwright (82/82 checks, no console errors):**
  - Practice flow; Exam pass/fail.
  - No key anywhere in the review below 80%.
  - Timer warnings and auto-submit (tested with `page.clock`).
  - Attempt counter; works with localStorage blocked.
  - One-page PDFs: certificate landscape, report portrait.
  - Light/dark at 1280 and 375 px with no horizontal scroll.
