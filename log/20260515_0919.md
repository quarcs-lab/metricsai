# 2026-05-15 09:19 — Add "Web Apps" Dropdown to Project Website Nav

## Work Done

### New "Web Apps" navigation entry on `index.html`
- Inserted a new top-level **Web Apps** item in the nav bar, immediately to the right of *Notebooks* and to the left of *Tutors*.
- Desktop behavior: clicking the button opens a dropdown panel rendered as a 2-column CSS grid (640 px wide) listing all 17 chapter web apps. Each row shows a monospace `Ch N` chip + the chapter title and links to `web-apps/chNN/dashboard.html` in a new tab (`target="_blank" rel="noopener"`).
- Mobile behavior: same 17 entries collapse inline under the hamburger menu via a chevron-toggle button. Tapping any entry opens the web app in a new tab and closes the hamburger menu.
- Accessibility: button uses `aria-haspopup`, `aria-expanded`, `aria-controls`; dropdown closes on outside-click and on Escape; chevron rotates 180° via a small CSS transition driven by `data-open="true"` on the wrapper.

## Decisions Made
- **Dropdown over standalone page or modal.** Other secondary nav items (Tutors, Videos) link to standalone pages, so a separate `web-apps.html` would have matched precedent; the user picked a dropdown for fastest access (1 click → web app) after seeing all three options previewed.
- **2-column grid (desktop)** rather than a single tall column: keeps 17 entries in ~9 rows without vertical scrolling.
- **Hard-coded chapter titles** in the dropdown (vs reading from a JSON manifest): mirrors the existing chapter-card pattern in the same file and avoids a build step.
- **Chapter titles stay in English when language toggle is set to ES**, matching the rest of the site (no chapter title is translated anywhere).
