```bash
for ch in 01 02 03 04 05 06 07 08 09 10 11 12 13 14 15 16 17; do
  python3 -c "
import re
t = open('web-apps/ch$ch/template.html').read()
def block(label):
    m = re.search(rf'\b{label}:\s*\{{', t); s = m.end(); d = 1; i = s
    while i < len(t) and d > 0:
        if t[i] == '{': d += 1
        elif t[i] == '}': d -= 1
        i += 1
    return len(re.findall(r'\"[^\"]+\"\s*:', t[s:i-1]))
print('ch$ch:', block('en'), '==', block('es'))
"
done
```

## Architecture pointers (where to find what)

- **`I18N` object** — top of each chapter's main `<script>` block in `web-apps/chNN/template.html`. Shape: `{ defaultLang: "en", storageKey: "language", en: { ... }, es: { ... } }`.
- **`t(key, vars)` helper** — same script block. Looks up the key in the active language, falls back to EN if missing, interpolates `{name}` placeholders via `s.split("{name}").join(value)`.
- **`applyLanguage(lang)`** — same script block. Persists choice to `localStorage`, swaps every `[data-i18n]` element via `innerHTML = t(key)`, then re-fires every registered `window.__rerender_*` so Plotly chart titles/axes/legends/hover templates re-paint in the new language.
- **`__rerender_<widget>` registry** — each widget IIFE registers its render function on `window.__rerender_<widget>`. Pre-existed for the dark-mode toggle; reused by the language toggle.
- **Site navbar** — `<nav class="site-nav">` markup injected at the top of each `<body>`. Houses the logo, 8 nav links, dark-mode + language buttons, and mobile drawer. Replaced the per-chapter `.header-controls` block during the navbar migration.
- **Migration script** — `scripts/migrate_webapp_navbar.py`. Idempotent, applies 11 transforms per chapter. Re-running on already-migrated chapters is a no-op. Documented in `log/20260515_1207.md`.
